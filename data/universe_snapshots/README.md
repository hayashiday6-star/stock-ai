# 上場していた会社の名簿（日付ごと）

`checks\廃止銘柄の取り込み.bat`（`stock-ai delisted-harvest`）が、
`YYYY-MM-DD.csv` を1日1ファイルで書き出す。中身はその日時点の上場一覧
（銘柄コード・社名・セクター・業種）である。

## なぜファイルで、なぜ git に入れるか

**取り直せないからである。** DB の株価は立花から作り直せるが、この名簿は
J-Quants の有料プランでしか取れず、解約予定は 2026-09-22 である。それ以降、
どこからも作り直せない。5年ローリング窓の外（およそ 2021-09 より前）は、
いま実行しても取れない。

## なぜ和集合ではなく日付ごとか

和集合しか持たないと、2023年に上場した会社を2021年の分位に入れられてしまう。
生存バイアスを直したつもりで先読みを持ち込むことになり、直す前より悪い。

分位を組むときは「**その日以前で最も新しい名簿**」を universe に使う
（`stock_ai.data.delisted.universe_as_of`）。

## 隣り合う2ファイルの差が、その期間に消えた銘柄である

DB との差ではない。DB は過去に取り込んだ分の集合であって上場一覧ではないので、
DB との差は「廃止された」と「そもそも取っていない」を混ぜる（実際に一度混ぜた）。

実測では年 49〜106 件が消えており、しかも年々増えている。
