## 8. 増担保規制の発動後ドリフト — **封印せず（§0 で止めた）**

**規制が掛かれば強制的に売らされる人が出る**——だからその後に下がるはずだ、
という説である。**機構がはっきりしている**ぶん、7本の失敗の後に残った最後の
候補だった。

### 何を測ったか（2026-09-16）

原本（`/markets/margin-alert`、2008-05〜2026-09）から発動を拾い、貸借銘柄・
流動性で絞り、**公表日の翌営業日の寄付きから14営業日**の超過リターンを、
**IS（2017-07-25 まで）だけ**で測った。

| | |
|---|---|
| 発動イベント | 1,414 件 → 貸借で 418 → 流動性で **409** |
| IS / OOS | **219 / 190** |
| 保有窓 | **14営業日**（解除までの中央値。式から出る） |
| 1イベントあたりのSD | **31.15%** |
| 検出できる差 | **1イベント 6.41%** |
| IS の取り高（ショート・費用引き後） | **1イベント −1.44%** |

### 3つとも、同じ向きを指した

1. **符号が逆だった。** 増担保が掛かった銘柄は、14営業日で市場を **+1.04%
   上回っていた**
2. **測る前にコミットした線（1.2%）を下回った。** 片側95%の下限は **−4.75%**
3. **検出できない。** 線の大きさを検出するだけで **5,431 件＝242年**要る。
   手元の OOS は 190 件

### 心配していたのは件数だった。縛っていたのは散らばりだった

登録時に書いた心配は件数である（イベント型は件数が命）。実際 OOS 190 件は、
2026-09-05 に自分で出した「1,000 件以上」に1桁足りない。

**だが縛っていたのは SD のほうだった。** 1イベント 31.15% は #7（月次・分位の
α で 1.84%）と桁が違う。**増担保が掛かるのは大きく動いた直後の銘柄**なので、
その後の14営業日も大きく動く。**母集団の選び方が、そのまま分散を決めていた。**

**仮にイベントが 1,000 件あっても届かない。**

### 上がる説として拾い直さない

IS で +1.04% 上回ったことを「規制後は上がる」として拾わない。**両側で当たりを
狙えば、どちらに転んでも当たりになる**（#9 で同じ形を禁じた）。拾うなら別の
1本で、別の事前登録が要る。

**「増担保規制の後にドリフトは無い」とも言わない。** 測ったのは IS であって
判定ではない。**言えるのは封印しないことだけである。**

**判定は消費していない。**（詳細は [PREREG_MARGIN_JP.md](PREREG_MARGIN_JP.md)
