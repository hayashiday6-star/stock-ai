## 11. 低ボラ × バリュー — **封印せず（§0 で止めた）**

**複合型の1本目である。** 構成要素は #7（`technical`）と #10（`fundamental`）
で、**種類をまたぐ。**

### なぜこの組か

**2026-09-05 に束ねた3本は、3本とも `technical` だった。** 合成 t −0.14、
最良の単独 +1.69 で符号が逆になり、因子探索はそこで閉じた。**その束には
`fundamental` が1本も入っていない。**

**閉じた結末は動かさない。** ここで測るのは `composite-gain` の r ではなく、
**複合型それ自体**である。r には「曖昧域で財務系の再測定はしない」と測る前から
書いてあり、そこには触らない。

### 封印前に決めてコミットしたこと（2026-09-16）

- **IS で試すのは1通りだけ**（等加重の z スコア合算）。重みは動かさない。
  **2通り目を回したくなったら封印しない**
- **封印しない線は「実測した往復費用の3倍」。** 数字ではなく規則で置いた——
  費用は入れ替わり率で決まり、それは測るまで分からないので、「年 X%」と
  決め打つと X の出どころを書けない。3倍にするのは #8 と同じ理由で、費用を
  超えるだけの線では #7 が入った帯にまっすぐ入るからである
- **合格には最良の構成要素単独を上回ることが要る**（PURPOSE の複合型ルール）
- **脚には判定を出さない。** 累計に数えるのは、この複合 **1本**だけ

### 気を付ける場所（**当たらなかった**）

登録した時点で危ないと書いたのは件数だった——バリューを足すと `pbr` の無い
銘柄月が落ちて断面が痩せ、分位が効かなくなる、と。

**実際は 1,011 対 1,067 で、減りは 5% しかなかった。** 月数も 106 対 106。
**書いた心配は当たらず、落ちたのは別の場所である。**
