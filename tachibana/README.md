# 立花証券・ｅ支店・ＡＰＩ のファイル

このフォルダの中身は **README 以外すべて gitignore 済み**である。

| ファイル | 中身 | 失ったら |
|---|---|---|
| `private.pem` | 秘密鍵。**資格情報** | **立花への登録からやり直し。** 作り直すと登録済みの公開鍵と合わなくなる |
| `public.txt` | 登録用に書き出した公開鍵 | `private.pem` があれば `keyfmt` で書き直せる |
| `session.json` | その日の仮想ＵＲＬ。復号済みなので**資格情報** | 消えてよい。次の実行でログインし直す |
| `history.json` | プローブの生の応答（株価のみ） | 消えてよい |
| `master.json` | 銘柄マスタの生の応答 | 消えてよい |

`private.pem` は POSIX では 0600 で作る。**例外メッセージにも内容を出さない。**

## 整理前は直下にあった

`tachibana_private.pem` のような名前でプロジェクト直下に散らばっていた。
旧い場所にしか無い場合、コードはそちらを読んで警告を出す
（`stock_ai.data.tachibana.resolve_path`）。移すには
`checks\立花のファイルを整理.bat` を実行する。

**鍵の作成コマンドは、旧い場所に鍵があると作成を拒否する。** 整理の途中で
見落として作り直すと、立花への再登録が必要になるためである。
