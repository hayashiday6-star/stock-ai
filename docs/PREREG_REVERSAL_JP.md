# 事前登録：短期リバーサル（日本株・ロングオンリー）

**状態：判定済み — 不合格（2026-09-04）。** 判定は §14 にある。

以下の設計はすべて、リバーサルのリターンを**1つも見ずに**決めたものである。

見たのは次の3つだけで、いずれも合否とは独立している。

- 母集団の件数（リターンを計算しないセンサス）
- 2001–2020 の**分散**（平均は計算していない。分散の推定は検定を消費しない）
- IS における「名簿あり − 生存者のみ」の**差**（水準ではなく差だけ）

**OOS は一度だけ回した。設計は一切変えていない。**

これまでの4本（`PREREG_ACCUMULATION_JP.md` / `PREREG_PEAD_JP.md` /
`PREREG_SUE_JP.md` / 予想修正）と違う点が2つある。

- **母集団も検出力も、封印の前に測ってある。** 決算ドリフトの2本は封印して
  から検出力が足りないと分かった。順序を逆にした
- **生存バイアスが「制約」ではなく「直した」状態で回る。** 日付ごとの上場名簿を
  ディスクに持ち、廃止された会社を universe に含める

---

## 1. 仮説

短期間に大きく下げた銘柄は、その後の短期間に反発する。

反発の理由は問わない。流動性の対価でも、過剰反応の巻き戻しでも、測るものは
同じである。**理由を特定しないことを、ここで明示しておく。** 後から都合の良い
説明を付けるのを防ぐため。

## 2. ユニバース

| 項目 | 値 |
|---|---|
| 市場 | 日本株（東証プライム・スタンダード・グロース） |
| 上場していたかの判定 | **日付ごとの名簿**（`data/universe_snapshots/`、月次） |
| 流動性の下限 | 判定日の**前日まで**の20営業日平均売買代金 1億円 |
| ベンチマーク | 1306（TOPIX連動ETF）。**営業日の暦もこれに合わせる** |

**名簿は「その日以前で最も新しいもの」を使う。** 全期間の和集合を使うと、まだ
上場していない会社を過去の分位に入れることになり、生存バイアスを直したつもりで
先読みを持ち込む。

売買代金は**生値**の終値×出来高で測る。調整済み終値に実出来高を掛けると、
分割前のバーを分割比率のぶん過小に見積もる。

### 価格系列の不連続をまたぐ窓は除外する

判定日側（5営業日）と保有側（20営業日）のどちらかに、**1営業日で ±50% を超える
動き**が入る銘柄日を落とす。

東証には値幅制限がある。いちばん緩い低位株でも1日で ±50% を超えることはまず
無い。超えているなら、そこで価格の系列が不連続になっている。

**極端なリターンを捨てているのではない。** 併合の前後で価格の単位が違うので、
その2点を割り算した値はそもそもリターンではない。実測（8308、2005年の1:1000
併合）では、`adj_close` 自体が併合をまたいでおらず、調整を通しても直らなかった。

検出は**直前に値のあった日**と比べる。営業日の暦に載せ替えたあとの欠測と比べる
と、売買停止を挟んだ併合が必ず素通りする。

2001–2020 での実測: **754 銘柄日**を除外。これを入れたままだと日次系列の
標準偏差が 24.42%、除外すると **3.64%** になった。

## 3. 並べ替えと分位

判定日 D の終値時点で、条件を通った全銘柄を **直近5営業日のリターン**
（`終値[D] / 終値[D−5] − 1`）の**昇順**に並べ、**その日の中で**5分位に割る。

- **分位1 = 最も下げた側。** これが買う対象である
- 分位は**日ごとに独立に**作る。ある日の分位1と別の日の分位1が同じ下落率とは
  限らない。それが日次で分位を組むということである
- 同順位は元の並び順で割る

### 実測された母集団（`reversal-census`、2026-09-03）

| | 値 |
|---|---|
| 営業日 | 6,245 |
| 1営業日あたりの通過銘柄数（中央値） | 968 |
| 5分位を作れなかった日 | 1 |
| 分位ごとの売買代金（中央値） | 4.7〜5.2 億円（**5分位で平らだった**） |

**小型に寄るという事前の見立ては外れた。** 流動性フィルタの内側では、分位に
よる規模の偏りが無い。

2001–2020 に限ると1営業日あたり中央値 812 銘柄、**1分位あたり最小 64／中央値
162 銘柄**。分位が1〜2銘柄になる日は無い（SUE版が壊れた形はここでは起きない）。

## 4. 売買ルール

| | |
|---|---|
| 分位を決める時点 | D の**終値** |
| エントリー | **D+1 の寄付き** |
| エグジット | **D+21 の寄付き**（20営業日保有） |
| 建玉 | 分位1を等金額で買うだけ。**ロングオンリー** |
| 費用 | **1往復 0.40%**（感度分析で 0.60%） |

**寄り引けを混ぜない。** 片側だけ一晩ぶんずれた引き算は、ベンチマークとの差に
一方向の偏りを作る。D の終値と D+1 の寄付きの間が1営業日空いているので、
「終値で並べて終値で買う」形の微細構造は入らない。

### なぜロングオンリーか

**空売りが実行できる前提を確かめた結果、できないと判断した。**

- 貸借銘柄は全体の **60.1%**。分位1の4割は空売りできない可能性がある
- しかも立花の `sSinyouC`（貸借区分）は**現在値**である。過去の日付に当てると
  先読みになる

実行できない戦略で合格を出すと、次に「ではロングだけで」となり、そこで測り直す
のは事後的な選択になる。**最初からロングオンリーを主要指標にする。**

費用 0.40% は、両建て前提の 0.80% の半分である。片側しか建てないため。

ベンチマークは銘柄側と同じ足で測る（D+1 の寄付き起点、D+21 の寄付き終点）。

## 6. 期間分割

| | 期間 | 用途 |
|---|---|---|
| 分散の推定 | 2001-01-04 〜 2020-12-31 | **平均は見ない。** 検出力の事前計算のみ |
| IS | 2021-09-04 〜 2023-12-31 | 形の記述、生存バイアスの実測 |
| **OOS** | **2024-01-01 〜** | **合否判定。一度だけ。** |

### なぜ 2021-09-04 からか

**J-Quants が名指しした境界である。** 2021-09-01 の名簿を頼むとこう断られた。

```
Your subscription covers the following dates: 2021-09-04 ~
```

分位を組むにはその日の名簿が要るので、名簿の無い日は判定日になれない。
**これより前は今後も直せない**（廃止銘柄の株価も同じ窓の中にしか無い）。

### なぜ長い期間を主要指標にしないか

2001–2020 を判定に使えば検出力は稼げる。採らない。理由は
`docs/HYPOTHESES.md` §6 に5点で記録した。要点は2つ。

- **この説では、バイアスが処置群そのものに乗る。** 買うのは下落率上位で、
  廃止される銘柄が最も濃く集まる場所がまさに分位1になる
- **失敗の形が非対称である。** 短い期間の失敗は偽陰性（見送る）。長い期間の
  失敗は偽陽性（汚染由来の合格を信じて資金を入れる）

## 7. 検出力 — 封印の前に計算した

2001–2020（判定に使わない期間）の**分散と自己共分散だけ**から求めた。
平均は計算していない。分散の推定は仮説検定を消費しない。

毎営業日エントリーして20営業日持つと、隣り合う観測は19/20の日を共有する。
独立と見なすと標準誤差を小さく見積もるので、Newey-West（Bartlett 重み、
ラグ20）で長期分散に直す。

| | 分位1 − ベンチ（主要） | 分位1 − 分位5（副次） |
|---|---|---|
| 日次SD | 3.64% | 3.84% |
| 上位1%の日を除いたSD | 3.34% | 3.53% |
| 重なりによる標準誤差の膨張 | 2.95x | 2.06x |
| OOS（630営業日）の標準誤差 | 0.43% | 0.32% |
| **t≥2.0 に必要な差** | **0.85%** | 0.63% |

日次系列そのものの分布は 最小 −18.1% ／ p1 −8.0% ／ p50 +0.2% ／
p99 +10.8% ／ 最大 +19.6%。**±50% を超えた営業日は 0/4,765。**

上位1%を除いても 3.64% → 3.34% にしか下がらない。**分散は少数の日でできて
いない**——「毎日どれくらい散らばるか」を測れている。

### この検証が持つ構造的な限界

費用のしきい値は 0.40%、検出に必要な差は 0.85%。**その間に帯がある。**

> **20営業日あたり 0.40%〜0.85% の効果は、儲かるが、この検証では検出できない。**

これは運ではなく設計から出る。不合格が出ても「効果が無い」ではなく
「**0.85% より小さい**」しか言えない。

参考: しきい値ぴったりの 0.40% を t≥2.0 で検出するには **約2,900営業日
（11年半）** が要る。

## 8. 合格基準

**OOS で一度だけ判定する。** 判定は次の2つを**両方**満たしたときのみ合格。

1. 分位1 − ベンチの平均が **+0.40% 以上**（費用を賄う）
2. Newey-West(20) の **t ≥ 2.0**

### 読み方の表（結果を見る前に確定させる）

| OOS の点推定（20営業日あたり） | t | 読み方 |
|---|---|---|
| ≤ 0% | — | **効果なし。** 説を閉じる |
| 0% 〜 +0.40% | — | **費用を賄えない。** 実行できないので閉じる |
| +0.40% 〜 +0.85% | t < 2.0 | **構造的な帯に入った。** 不合格。ただし「効果が無い」ではない。前向きに貯める |
| +0.40% 〜 +0.85% | t ≥ 2.0 | 合格（事前の見積もりより分散が小さかった場合） |
| ≥ +0.85% | t < 2.0 | 点推定は十分だが有意でない。前向き検証へ |
| ≥ +0.85% | t ≥ 2.0 | **合格** |

**3行目が今回いちばん重要である。** SUE版のときと同じ理由で、ここを先に
決めておく。判定が出てから「惜しかった」と基準を動かすのを防ぐ。

**この表は人が読んで当てはめるのではなく、コードが当てはめる**
（`stock_ai.backtest.reversal.verdict`）。前回は結果を見てから基準が動きかけた。
表の当てはめを手作業に残すと、そこが緩む余地になる。

**基準を緩めることは、どの結果が出てもしない。** 帯に入ったときの次の一手は
「2026年9月以降のデータを前向きに貯める」であって、t の閾値を下げることでは
ない。

## 9. 生存バイアスの実測 — 測定済み

IS（2021-09-04 〜 2023-12-31）で、**同じ日を2回**回す。変えるのは universe
だけ。

- 名簿あり（後に上場廃止になった会社を含む）
- 生存者のみ（いま残っている銘柄だけ。**意図的に先読みしている対照**）

差がバイアスの大きさと符号になる。**OOS では絶対に回さない。**

### 実測（2026-09-04、IS）

| | 値 |
|---|---|
| 共通の営業日 | 570 |
| 1日あたりの銘柄数（名簿あり） | 1,438 |
| 1日あたりの銘柄数（生存者のみ） | 1,322 |
| **名簿あり − 生存者のみ** | **−0.040%**（20営業日あたり） |

**符号は負。生存者だけで測ると効果を大きく見せる。** これまで「TOB は
プレミアム付きで消え、破綻はゼロになるので向きは分からない」と書いてきたが、
**正味では下向き**だった。分位1（下落率上位）に集まるのは破綻寄りの銘柄で、
TOB のプレミアムを打ち消して余る。

大きさは小さい。

| 比較対象 | 値 | バイアスとの比 |
|---|---|---|
| 生存バイアス | 0.040% | — |
| 費用のしきい値 | 0.40% | **10分の1** |
| 検出に必要な差 | 0.85% | **21分の1** |
| 中止条件（§12） | 1.0% | **25分の1** |

**中止条件には当たらない。判定に進む。**

universe は1日あたり 1,438 対 1,322 で **8.8% 違う**。それだけ入れ替えても
分位1のリターンが 0.040% しか動かない、というのがこの実測の中身である。
廃止銘柄が「全部ゼロになる」わけではなく、TOB とほぼ打ち消し合っている。

**この数字はこの説だけのものではない。** これまでの事前登録がすべて但し書きで
済ませてきた量に、初めて符号と大きさが付いた。

### 判定期間の銘柄数について（検出力は控えめに見積もられている）

§7 の検出力は 2001–2020 から推定したもので、当時は1分位あたり中央値162銘柄
だった。**判定期間は1分位あたり約288銘柄ある**（1,438 ÷ 5）。銘柄数が多い
ぶん個別要因は薄まるので、実際の標準誤差は §7 の見積もりより**小さくなる
方向**である。

**それでも §7 の数字を基準として使う。** 判定期間の銘柄数を見てから必要な差を
下げるのは、事後的な緩和になる。見積もりが控えめであることを記録として
残すだけにする。

### 直せた範囲（2026-09-04 実測）

| | 値 |
|---|---|
| 名簿 | 63件（2021-09-04 〜 2026-09-04） |
| 名簿に一度でも出た銘柄 | **4,124** |
| 期間中に消えた銘柄（名簿同士の差の延べ） | **527** |
| **株価が取り込めなかった銘柄** | **16**（名簿の 0.4%、消えた銘柄の 3.0%） |

**4,124 は、コミット済みの63ファイルを読み直して数えた値である。** 取り込みの
実行時はいったん 4,097 と報告していたが、あれは「その実行で要求した日付」の
範囲しか数えていなかった。境界の名簿（2021-09-04）は別の実行で取っており、
翌日の実行では要求されない。差の27銘柄は、**株価を取りに行く対象からも漏れて
いた。**

取り込み側がディスク上の名簿すべてを見るように直して再実行した結果、27件の
うち **23件は既に株価があり、4件が新たに取得不能と判明**した。取れない銘柄は
12 → **16** で確定した。

判明している12件: `1440` `2230` `3039` `3456` `4250` `4383` `7056` `7125`
`7790` `9261` `9276` `9388`（残る4件のコードは実行時の出力から拾っていない）。

いずれも API は 200 を返すが、使える行が1つも無い。**再試行で取れるものでは
ない**（4回とも同じ結果）。件数は `checks\解約前の棚卸し.bat` の「名簿にあって
株価が無い」で何度でも数え直せる。

株価が取れなかった12件: `1440` `2230` `3039` `3456` `4250` `4383` `7056`
`7125` `7790` `9261` `9276` `9388`。

いずれも API は 200 を返すが、使える行が1つも無い。**再試行で取れるものでは
ない**（3回とも同じ結果）。名簿の 0.3%、消えた銘柄の 2.3% にあたる。

**この12件は判定を歪めない。** 株価が1本も無い銘柄は、名簿あり版でも生存者
のみ版でも同じように分位に入れない。**両方から等しく欠ける**ので、§9 の差
そのものには効かない。効くのは「直せた範囲」の見積もりだけで、その数字が
上の表である。

（この理屈が成り立つのは、欠けているのが**価格**であって名簿ではないため。
名簿が欠けていれば universe が変わり、差に効く。名簿は63件すべて揃っている。）

これまでの事前登録はすべて「上場廃止銘柄が入っていない」と書きながら、その
大きさも符号も数字にしていなかった。TOB・完全子会社化はプレミアム付きで消え、
破綻はゼロになるので、向きは自明ではない。**プロジェクト全体で使い回せる数字**
になる。

実行は `research\生存バイアスの大きさ.bat`。

## 10. 先読みバイアスのチェックリスト

| 項目 | 対処 |
|---|---|
| 名簿の先読み | その日**以前**で最も新しい名簿だけを使う。テストで固定 |
| 分位形成と売買の同時性 | D 終値で分位、D+1 寄付きで売買。1営業日空く |

| ベンチマークの窓 | 銘柄側と同じ足（寄付き起点・寄付き終点） |

| バイアスの実測期間 | 2023-12-31 まで。**それ以降を渡すとコマンドが拒否する** |

## 11. 主張できないこと

判定が合格でも、次は言えない。

- **2021-09 より前について何も言えない。** 生存バイアスを直せない期間である
- **空売りを含む戦略について何も言えない。** 測っていない
- **なぜ反発するのかについて何も言えない。** 理由は仮説に含めていない
- **0.85% より小さい効果の有無について何も言えない**（不合格の場合）
- 実際の約定価格について何も言えない。寄付きで理論値どおり約定する前提である

## 12. 中止条件

次のいずれかで、判定を回さずに閉じる。

- IS で1分位あたりの銘柄数が中央値 20 を下回る（分位が意味を持たない）
- 生存バイアスの実測が **±1.0% を超える**（20営業日あたり）。その場合、
  バイアスの大きさが検出したい効果と同程度以上になり、**何を測っているか
  分からなくなる**
- 名簿の欠けている月が3か月以上ある

## 15. 何が言えて、何が言えないか

### 言えること

- **2021-09-04 以降の日本株で、この設計の短期リバーサルは効いていない。**
  点推定は負で、費用を賄うどころか符号が逆である
- 生存バイアスを直した universe で測った。**「廃止銘柄を入れたから負けた」
  のではない**（バイアスは −0.040%、結果の10分の1）

### 言えないこと

- **「効果が無い」とまでは言えない。** t = −0.99 は、正の側でも負の側でも
  有意でない。**0.85% より小さい効果の有無について、この検証は何も言えない**
  （§7 に書いたとおり、それが最初から分かっていた限界である）
- **2021-09 より前について何も言えない。** 生存バイアスを直せない期間である
- 空売りを含む戦略について何も言えない
- 保有期間や下落率の測り方を変えた版について何も言えない。**変えて測り直す
  のは別の説であり、この判定の続きではない**

### 主要指標の作りについて、判定後に気付いたこと

**分位1だけでなく、5分位すべてがベンチマークを下回っている。**

| | 分位1 | 分位2 | 分位3 | 分位4 | 分位5 |
|---|---|---|---|---|---|
| ベンチマーク差 | −0.39% | −0.31% | −0.30% | −0.18% | −0.31% |

分位平均は +1.36% で、ベンチマークは +1.66%。つまり **−0.30% は「等金額で
持った銘柄群が時価総額加重の指数に負けた」分**であって、リバーサルの並べ替え
とは関係がない。分位1が分位平均から離れている分は **−0.09%** しかない。

主要指標（分位1 − ベンチマーク）は、リバーサルの効果と「等金額 対 時価総額
加重」の差を**混ぜて**測っていた。空売りが実行できない以上ロングオンリーに
するのは正しかったが、比較対象をベンチマークに置くとこうなる。

**ただし判定は変わらない。** この混ざりを取り除いた分位1 − 分位5 も
−0.079%（t = −0.23）で、やはり何も無い。**2つの測り方が同じ答えを出している。**

### 検出力の見積もりは当たっていた

| | 事前（2001–2020 の分散から） | 実測（OOS） |
|---|---|---|
| 営業日 | 630 | 629 |
| 標準誤差 | 0.43% | 0.399% |
| t≥2.0 に必要な差 | 0.85% | 0.80% |

**封印前に計算した検出力が、判定でほぼそのまま再現した。** 判定に使わない期間
の分散から、判定期間の標準誤差を当てられる——この手順は次の説でも使える。
