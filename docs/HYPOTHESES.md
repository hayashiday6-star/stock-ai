**#1〜#8 の8本は「ネット記事等（URL未記録）」である。** これが本当のところで、
ユーザーがそう述べた（2026-09-16）——**ネット記事などで見かけた説である。**

### あとから論文を探して埋めない

**それは、いま無い出典を作ることである。** ひな形の §0 がこう戒めている。

> 「同じ設計」を緩めない。…**転記すれば「出典のある数字」の見た目をした別物
> が §0 に入る。出典の無い数字より質が悪い**——検証できないものを、検証した
> ように見せることになる。

ネット記事で見かけた説を検証したのに、あとから見つけた論文の数字を見込み値に
使えば、**母集団も保有期間も違う別物**が §0 に入る。**空欄のほうが正直である。**

### 出典が無くても封印はできる

見込み値の梯子（`PREREG_TEMPLATE.md`）は、文献値が無いときに **2段目——
自分の IS から推定する**を用意している。**1段目が埋まらないだけで、止まらない。**
#8 は既にそうしていて、「報告された文献値を、こちらは持っていない」と明記して
いる。

### では、これから何を書くのか

論文ではなく **「誰がどこでそう言っているか」** である。俗説にとっては、
ネット記事こそが正しい出典である。要るのは **URL ＋ 主張の一文 ＋ 見た日**
の3つだけで、登録のときに貼れば済む。

**2つのために要る。**

1. **主張が後から動かないように固定する。** 結果を見てから「検証したかったのは
   そういう意味ではない」と言い換えられなくする。`封印後に基準を変えない` の
   親戚である。
2. **公開レポートが成り立つように。** 「X を検証して落ちた」は、**X が誰の主張
   なのか書けないと弱い。** 「そんな説は誰も言っていない」で終わる。

### #7 の §0 には、出典の無い見込み値が入っている

`PREREG_LOWVOL_JP.md` は「文献の低ボラ超過（年0〜2%）」を §0 の見込み値に
使っている。**その年 0〜2% に出典の記録が無い。**

**いまから探して後付けしない。** 上に書いた理由そのものである。判定も変えない
——封印して回した結果である。**レポートにそう書き添えるのが正直な扱いである。**

### 判定の線は、測ったら甘かった（2026-09-17）

**陰性対照を 400 回回したら、帰無の下で `t` の SD が 1.12 だった**（1.00 の
はず）。`research\陰性対照を400回.bat`。

**`t ≥ 3.02` は 0.25% のつもりで、実際は 0.71% だった。3倍甘い。**

原因は Newey-West の標準誤差が 100ヶ月程度では小さめに出ることである。
標準誤差が小さければ `t` は大きくなる。

**必要な `t` を 3.02 → 3.39 に上げた**（`multiplicity.calibrated_t`）。

**これは「結果を見てから基準を緩める」の逆である。** 緩めるのが禁じ手であって、
**測って厳しくするのは訂正**である。しかも説のデータではなく、**対照から出た数**
である。**今後の封印にだけ当てる**——#7 は封印済みなので `t ≥ 2.0` のままである。

#### 候補は2つある。直し方が正反対である

最初は生存フィルタ1つを疑って書いた。**コードを読み直したら、もう1つ、
そちらのほうが重そうな候補が出た**（2026-09-17）。

- **(A) 加重の違い。** 引いている相手は `1306`（時価総額加重の TOPIX ETF）で、
  対照が引くのは**上場 JP 銘柄からの一様抽選**——実質**等加重**である。
  小型が指数に勝っていれば、**情報ゼロでも平均はプラスになる。**
  **これは不具合ではない。** 直すところはコードに無く、**引く相手のほう**である。
- **(B) 生存フィルタ。** 窓の途中で価格が途切れるイベントは落ちる（上場廃止・
  長期停止）。**落ちるのは悪く終わった側に偏る。** こちらは不具合である。

**どちらも #5・#8 に同じだけ掛かっている。**

#### 切り分けるために、捨てた件数を出すようにした

**この関数は5箇所で黙って `continue` していた。** 引いた 2,000 件のうち
何件が、どの理由で落ちたのかを、**対照も #5・#8 も一度も出していなかった。**

`event_sample` が処分の内訳を返す。内訳は足すと引いた件数に一致する
（合わなければ生成時に落ちる）——**どこにも数えられずに消える経路を作らない。**

そして**窓が足りない理由を2つに分ける。**

- **上場廃止・停止**（その銘柄の足が全体の最終日より前で切れている）——偏る
- **期間の端**（足は最後まで在り、イベントが新しいだけ）——偏らない

混ぜると、偏る経路が偏らない経路に薄められる。

**(B) は測れる。** 落ちた側を**足の在るところまで**で測り、
`割合 × (残った平均 − 落ちた平均)` を出す。**残りが (A) に当たる。**
推測ではなく引き算になる。

#### 答えは (A) だった（2026-09-17、400回・800,000 件）

|---|---|---|
| 使えた | 522,734 | 65.3% |
| 価格が1本も無い／その日に足が無い | 275,057 | 34.4% |
| **上場廃止・停止で窓が切れた** | **941** | **0.1%** |
| 期間の端で窓が足りない | 1,268 | 0.2% |
| 入る値か降りる値が欠測 | 0 | 0.0% |
| 指数に対応する日が無い | 0 | 0.0% |

| | 1イベントあたり |
|---|---|
| 銘柄側 | **+1.11%** |
| 指数側 | **+0.88%** |

**疑っていたほうではなかった。** 上場廃止で落ちたのは 800,000 件中 **941 件**
で、しかも**落ちた側は残った側より悪くなかった。** 生存フィルタは、最悪でも
0.12% しか説明できない位置にある（落ちた側が全損でも `0.1% × 1.0`）。

**残りはすべて加重の違いである。** `1306` は時価総額加重、引くほうは一様抽選で
実質等加重。**それだけで、情報ゼロの並びが指数に 20営業日で +0.22% 勝つ。**
年に直すとおよそ +2.8% で、小型株の割増としてありふれた大きさである。

**分解は構成上ぴったり閉じる**——`差 = 銘柄側 − 指数側` は超過の平均そのもの
なので、残差は無い。説明しきれていない分は無い。

#### 道具が、自分の表を否定する行を刷っていた

同じ出力の最後に **「いちばん疑わしいのは、窓の途中で価格が途切れるイベントが
落ちることである」** と刷っていた。**そのすぐ上の表に、押し上げ −0.00% と
出ているのに、である。**

決め打ちの犯人を書いたからで、**測った分解を読み上げていなかった。**

警告は分解を読む形に直し、**決め打ちが戻らないことをテストで留めた。**

#### 34.4% は2つのものが潰れていた

「価格が無い」の1行に、**直すべき穴**（名簿に在るのに価格が1本も無い銘柄）と
**直しようのない構造**（上場前・廃止後・停止）が混ざっていた。乱数で日と銘柄を
別々に引けば後者は当たり前に大量に出るので、**前者がそこに薄められる。**

本物の説では、**前者に落ちたイベントは黙って消える。** 別に数えて、

なるので、**気付いた時点で計算を止めた。**

#### 直しが、別のものを壊した

本物の窓を外したら、**偽の観測が作れなくなった。** 偽の窓が本物の窓を挟むと、
「窓の外」が**本物の窓だけになり、除外して空になる。** 空にならない回も、
**長さが 4〜22日 とばらついていた**（本物は常に約16日）——**同じ推定量を
測っていることにならない。**

窓の外を**その隙間のふつうの日に限った**（12〜15日で安定）。

#### 直したら、4つの読みが一致した

| 読み | 汚染あり | **直した** | 帰無なら |
|---|---|---|---|
| `t` の平均 | +0.40 | **+0.01** | 0.00 |
| 1月替わりあたりの差 | — | **−0.01%** | 0.00% |
| `\|t\| ≥ 3.02` | 0.75% | **0.25%** | 0.25% |
| `\|t\| ≥ 1.96` | 8.2% | **6.0%** | — |
| `t` の SD | 1.02 | **1.05** | 1.00 |

**`|t| ≥ 1.96` の 6.0% は、SD 1.05 の正規分布なら 6.2%。** 別の切り口が同じ
ことを言っている。

**イベント型の +0.49 と同じ形に見えたが、原因は違った**——あちらは加重の違い
（データ側）、こちらは対照の作り（こちら側）。**「前と同じだろう」で
済ませない。**

### 予算は **20 本**（2026-09-16 に決めた）

| | |
|---|---|
| 予算 | **20 本** |
| 全体の有意水準 | 両側 **5%** |
| 1本あたり α | **0.0025** |
| **必要な t** | **3.02** |

**20 にした理由。** 判定を消費したのが 5 本、登録して未判定が 3 本。複合型は
組み合わせ1通りにつき1本なので、本数はこれから速く増える。20 ならあと 12 本
ぶん残る。

**小さく取ると、超えた日に予算を取り直すことになる。** それは線を動かすこと
で、このプロジェクトがいちばん嫌う形である。**一度決めて、触らない。**

**t ≥ 3.02 は高い。** 文献に載っているアノマリーの多くは、この線では §0 を
通らない。#7 は t≥2.0 で必要な差が年 4.0%、文献の見込みが年 0〜2% だった——
**t≥3.02 なら §0 で止まっていた。** 実際その説は落ちたので、止まったほうが
良かったということになる。

**それは補正が厳しすぎるのではなく、「全体で 5%」という保証がそれだけ強い
ということである。**

### 緩めたくなったら、予算ではなく α を動かす

**予算を縮めるのは「何本試すつもりか」を偽ることである。** α を上げるのは
「どれだけの誤りを許すか」を決め直すことで、**そちらは正直に書ける。**

どちらも線は下がるが、意味が違う。1本も §0 を通らないと分かったときに見る
のは α のほうで、そのときは**なぜ 5% では足りないのかを書いてから**動かす。

### すでに封印した説の線は動かさない

#7 は `t ≥ 2.0` で封印してある。本数が増えたからといって遡って上げるのは、
**判定が出たあとに基準を変えること**である——`docs/PURPOSE.md` が禁じている
当のものである。

**掛かるのは、これから封印する説だけ。** そして予算は、`power-gate --budget N`
に渡したうえで**事前登録に書いてから封印する。**

**#8 が最初の対象になる。** まだ封印していないので、ここで決めれば後から動か
すことにならない。**封印したあとでは遅い。**

**予算そのものはまだ決めていない。** 決めるのは人間である。

**種類のタグは 2026-09-16 にこちらで割り当てた。** 出典に書いてあったのではない。
#2〜#5 は決算・会社予想の開示が要るので `fundamental`、#1・#6・#7 は価格と出来高
だけで計算できるので `technical`、#8 は需給（信用規制）なので `anomaly`。
**違うと思うものがあれば直すこと。**

### 20年に伸びたとき、どれが戻ってくるか（2026-09-12）

2026-09-15 からの Premium で、**日付ごとの名簿と廃止銘柄の株価が 2006-09 まで
遡れる。** いま 5年しか無いものが 20年になる。

**「長くすれば通る」ではない。** 判定済みの説を長い窓で回し直すのは**2回目の
判定**である。まず、閉じた理由で分ける。

| 3 | PEAD（会社予想差） | OOS で符号が反転 | 同上 |

見えない」側であって、「向きが逆だった」側ではない。**ここを混ぜると、落ちた
説を全部「もう一度」と言えてしまう。**

#### #7 は、20年でも足りない

**だから #7 は戻さない。** 「あと少し」に見えるが、計算すると足りない。
**計算せずに回せば、帯にもう一度入って判定を1回失う。**

判定を消費しない。

#### `composite-gain` に財務系の因子を繋がない（2026-09-16）

複合型に着手して、`factor_panel` に**バリュー（PBR）**を足した。束ねた3本は

**そのうえで、`composite-gain` には繋がなかった。**

`composite-gain` の閾値は、測る前にここに書いてある——**「曖昧域は打ち切り。
財務系での再測定はしない」。** バリューを足して r を測り直すのは、**その禁止
そのものである。**

「複合型は別の問いだから当たらない」とは言える。実際 PURPOSE では、複合型は
検出できる差を下げるための道具ではなく、**それ自体を登録して判定する説**で
ある。**だが、その言い分の形が問題である。** 「別の問いだから規則は当たら
ない」は、**測定後にしか出てこない理屈**と見分けが付かない。

だから分けた。**複合型は自分の事前登録と自分の §0 を持ち、OOS で判定する。**
`composite-gain` の r は 2026-09-05 のまま動かさない。**因子探索は閉じたまま
である。**

**7本の共通点が見えてきている。** 買いのみ・月次以下の頻度・150ヶ月前後
という形では、年 1〜4% の効果は構造的に検出できない。**縛っているのは因子で
はなく設計である。**

## 1. アキュムレーション5条件 — 中止（検証不能）

### 何を調べようとしたか

「静かに下げてきた低位株に、ある日ふつうの5倍の出来高が入る」——
それを買えば、その後20営業日で市場平均を上回るのではないか。

### なぜ閉じたか

**現象そのものは 11,014 件見つかった。問題は、その 97.5% が「自分が売買
できない銘柄」で起きていたことである。**

| 段階 | 残った件数 |
|---|---|
| 5条件を満たすスパイク | 11,014 |
| ＋ 普段から1億円の商いがある銘柄に限る | **279**（−97.5%） |
| ＋ 決算や権利落ちなど材料のある日を除く | **68** |

事前登録は「OOS で100件以上」を要求していた。68件では**リターンを計算する
前の段階で条件に届かない**ので、そこで打ち切った。

言い換えると:

> **この5条件が拾う現象と、自分が売買できる銘柄の範囲が、ほとんど交わって
> いなかった。** 「静かな低位株の出来高スパイク」は、そもそも小型で
> 商いの薄い銘柄で起きることだった。

### 当初の見立てが外れた点

打ち切りの筋書きとして「出来高5倍は決算発表日の出来高を拾っているだけでは
ないか」を想定していた。**実測は違った。** 流動性のある279件のうち、材料日の
内訳は **権利落ち関連 95件 に対して決算 31件** で、権利確定に伴う売買のほうが
決算の3倍多かった。

### この件で見つかった実装の欠陥

流動性フィルタを「スパイク当日の売買代金」で判定していたとき、**除外は
0件だった**。出来高が5倍になっていれば、それだけで1億円を超えてしまう。
**効いていないフィルタが、効いているように見えていた。**
20日平均に直したのは「厳しくした」のではなく、**初めて効かせた**ことになる。

## 3. 決算後ドリフト（会社予想との差で並べる）— 不合格

### 何を調べようとしたか

#2 と同じ現象を、**別のものさし**で測り直した。「発表日にどれだけ株価が
動いたか」ではなく「**会社が出していた予想を、実績がどれだけ上回ったか**」
で並べ替える。

#2 の不合格が「ドリフトが無い」せいなのか「並べ方が悪かった」せいなのかを
分けるための追試であって、新しい説ではない。**セクション3-3（並べ替える
変数）以外は、#2 の封印文書からそのまま写した。**

### なぜ閉じたか

**IS ではこの検証で最も良い形が出た。それが OOS で反転した。**

| | IS 2021-2023 | OOS 2024-2026 | 併合 |
|---|---|---|---|
| 上位分位 − 下位分位 | **+3.51%** | **−3.02%** | **−0.29%** |
| t値 | 1.48 | −1.77 | −0.20 |

IS では分位の階段が**単調**だった（−0.98 / +0.55 / +1.22 / +1.29 / +1.64）。
差は両端の2点しか使わないので、単調性のほうが強い証拠になる。

OOS ではその階段が**逆さま**になった（+3.47 / +0.81 / +1.58 / +1.19 / −0.06）。
**会社予想を最も下回った銘柄が、その後いちばん上がっていた。**

IS と OOS を合わせると **−0.29%（t = −0.20）** で、実質ゼロである。
符号が逆で、大きさがほぼ同じで、どちらも有意でない——
**同じ分布から2回引いた2つの数字として自然な形。**

### 主張できないこと（重要）

**「決算ドリフトは存在しない」とは言えない。** 言えるのは次までである。

- この検証が検出できるのは **+3.7〜4.2% 以上**。それ未満の効果があっても
  見えない
- 驚きが大きいのは**小型株に偏る**が、売買代金1億円のフィルタでその大半が
  落ちている。**現象が住んでいる場所を、この検証は測っていない可能性がある**
- 通期決算の短信は、実績と**同時に翌期の予想も出す**。手計算した6件のうち
  3件で、実績の驚きと当日の株価反応の符号が逆だった。
  例: トヨタ 2022-05-11 は前期実績を予想より14.5%上回りながら、資材高で翌期の

### 2026-09-04、原因が確定した — 分割・併合の調整漏れ

診断つきで回した結果。

|---|---|---|
| 8308 | 2005-07-25 | **+125,028.2%** |
| 4777 | 2014-12-15 | +1,260.8% |

**8308 の1件だけで、その日の分位平均が +772% 動く。** 4,765日で割って平方根を

つまり 24.42% は値動きではなく、**分割・併合の調整漏れの大きさ**だった。

数字を出さずに止まるようにした。

### 8308 を実際に見た（2026-09-04）— 予想した2つのどちらでもなかった

```
2005-07-26  終値     197   調整後     2.0   調整係数 0.0100
（2005-07-27 〜 08-01 は足が無い）
2005-08-02  終値 204,000   調整後 2,040.0   調整係数 0.0100
```

りそなホールディングスの **1:1000 の株式併合**である。足が無い4営業日は
併合による売買停止。

**調整係数は前後とも 0.0100 のまま。** 系列が併合をまたいでいない。つまり
「調整が無い」のでも「生値だけが飛んでいる」のでもなく、**`adj_close` 自体が
不連続**だった。`split_adjusted` を通しても直らない。

### 直し方 — 極端なリターンではなく、尺度の変わり目をまたぐ窓を捨てる

**東証には値幅制限がある。** いちばん緩い低位株でも1日で ±50% を超えることは
まず無い。超えているなら、そこで価格の系列が不連続になっている。

そこで、判定日側（5日）と保有側（20日）のどちらかに ±50% を超える1日の動きが
入る銘柄日を落とす。**極端なリターンを捨てているのではない。** 併合の前後で
価格の単位が違うので、その2点を割り算した値はそもそもリターンではない。

検出は**直前に値のあった日**と比べる。営業日の暦に載せ替えたあとの欠測と
比べると、**売買停止を挟んだ併合が必ず素通りする**（8308 がまさにこれ）。

判定日側も見るのは、逆向きの併合で「大きく下げた」ことにされた銘柄が分位1に
入り続けるためである。保有側だけ見ていると取り逃す。

落とした件数は `research\リバーサル検出力.bat` が毎回表示する。

説明がつく以上、欠陥の証拠にはならない。**

**2. 数字を出さずに止めたのが誤り。**
「汚染された分散から数字を出さない」つもりだったが、**止めたせいで「除外が
効いたかどうか」を測る手段まで失った**。保留は情報をゼロしか生まない。

**次の説は、これらの上から始められる。**

### 判定期間を 2021-09 以降にした理由（2026-09-03 決定）

長い期間（2001年〜）を主要指標にすれば検出力は稼げる。それを採らない。

**1. 2001-2020 の生存バイアスは、今後どれだけ時間をかけても直せない。**
廃止銘柄の株価も 2021-09 以降しか取れない（実測で 1352 も 1737 も 2022年
までしか返らない）。「いまは直せない」ではなく「永久に直せない」。長い期間を
主要指標に置けば、その汚染は最後まで残る。

**2. この説では、バイアスが処置群そのものに乗る。**
買うのは直近の下落率上位である。廃止される銘柄が最も濃く集まる場所が、
まさに分位1になる。全体に薄く乗る誤差ではない。

**3. 符号が分からないので、事後の補正もできない。**
TOB・完全子会社化はプレミアム付きで消え、破綻はゼロになる。向きが決まらない
ぶん、「多少楽観側に出る」という程度の話にならない。**結果の大部分が説明の
つかない要因でできている可能性がある**、という話になる。

**4. 折衷案（長期を主要・クリーンを副次）には、良い答えが存在しない。**
長期が合格でクリーンが不合格のとき、合格と書けない。書けないなら主要指標は
副次に従属しており、それは副次が主要だということである。逆に一致するなら、
短い期間で得られる結論を、汚染された指標を経由して得ただけになる。
**上振れの余地しかない設計になる。**

**5. 失敗の形が非対称である。**
短い期間で失敗すると偽陰性——効果があるのに検出できず、見送る。長い期間で
失敗すると偽陽性——汚染由来の合格を本物と信じ、実際に資金を入れる。
**副収入を作るのが目的である以上、この2つは等価ではない。**

代償ははっきりしている。センサスが見つけた 6,245 営業日のうち、判定に使える
のは 2021-09 以降だけになる。**2001-2020 は分散の推定にしか使わない**
（平均は見ない。分散の推定は仮説検定を消費しない）。

## 推定量の校正（**判定ではない**。回す前に宣言する）

**2026-09-05 に、EDINET の遡及範囲を確かめる前に書いた。**

### これは判定ではない

- **#6 と #7 は判定済みで閉じている。** ここで t を計算するのは推定量の校正で
  あって、説の合否ではない
- **この数字を合否の主張に使わない。** t が 2.5 で出ても、#7 が通ったことには
  ならない。#7 の判定は α +0.242%、t +1.70 で確定している
- 使い道は1つだけ。**§0 ゲートに掛ける「検出できる差」を、どの推定量で計算

**書かずに回すと、t が 2.5 で出たときに使いたくなる。** だから先に書く。

### なぜ SD 比ではなく t 比か

**SD だけを揃えると、同じ問題が効果の側に移る。**

分位ソートの α は上位20%と下位20%の差である。断面が正規なら上位20%の平均は
約 +1.40σ、下位は −1.40σ なので、

> **分位スプレッド ≒ 2.8 × 1σチルトのリターン**

推定量を変えると SD も効果も一緒に縮む。**SD だけ測って比を掛け、そこに文献の
分位スプレッドの効果量を当てると、2.8倍の改善が無料で出たように見える。**
このプロジェクトが繰り返し避けてきた型が、SD 側ではなく effect 側に出る形で
ある。

**t は無次元なので、これを構造的に回避する。** SD 比は診断として併記するが、
§0 ゲートに掛けるのは **t 比**にする。

### 期待値は控えめに置く（先に書く）

分位ソートと横断回帰の t は、実務上そこまで変わらないのが普通である。横断回帰

も小さくなるので相当程度は相殺する。**

**2倍を期待しない。** #7 は必要 年4.0% に対し実測 年2.9% なので、**1.38倍
あれば足りる。** その水準なら射程内である、というだけの話として扱う。

**1つ目（分位ソート → 横断回帰）は 0.93倍で終わった。** 効かなかった。

**残っている手は1つだけである。** どの説も**市場βしか引いていない。** バリュー
や低ボラのスプレッドは大きな業種の賭けを抱えているので、そこを抜けば残差の
散らばりは下がる。**効果そのものが業種の賭けでなければ `t` は上がり、業種の
賭けだったなら下がる。どちらに出ても答えである。**

**#7 の事前登録に既に書いてある**——「偏りが無いのか粗くて見えないのかを、この

**候補3本を封印前に閉じたので、8本目の判定はまだ手つかずで残っている。**

| 候補 | 落ちた場所 |
|---|---|
| 1 値幅制限の翌日 | 執行（翌日始値のギャップ中央値 +5.37%、15.4% は買えない） |
| 2 売買停止明け | 件数（37件） |
| 3 52週高値更新 | IS の選別（−0.19%） |

**これまでの7本はすべて封印して回してから落ちた。今回の3本は、どれも封印前で
ある。** 関門が働いた形になっている。

**候補のうち「決算日の短期反転」は閉じたままにした**（2026-09-05）。検出力
だけなら最も通しやすいが、#2・#3・#5 と同じ日付集合の3度目になる。窓が
12分の1で現象が逆向きだから別物だ、という理屈は、**測る前ではなく「通したい」
ときに出てくる形をしている。** 3度目で合格が出ても、本物か「3回試したうちの
1回」かを後から読み分けられない。読み分けられない合格は使えない。

再開する条件は1つだけ決めてある。**新しい日付集合が手に入ったとき。**

**その結果として、J-Quants から会社予想と開示時刻を取り足すのをやめた**
（2026-09-05、`docs/JQUANTS_EXIT.md`）。決算ドリフトのテーマ用のデータで、
そのテーマも因子探索も閉じたため。2021-09 〜 2026-09-04 の分は手元にあるので、
過去5年を使う検証は再開しても組める。

### まだ確かめていないこと

有報の「主要な経営指標等」は**1本で5期ぶん**持つので、書類が 2016-09 まで
届くなら、年次の数字自体は 2012年ごろまで埋まりうる（**約14年 = 168ヶ月**）。

**ただし、これは point-in-time ではない。** 2016年の有報が載せる2012年の値は
遡及修正済みかもしれず、2012年の組成時点で知り得た値とは限らない。
`docs/EDINET.md` が既に「EPS だけが遡及適用済み」と記録している。

**先読みの度合いを測ってから使う。** いまの設計に入れるのは 111ヶ月までとする。

## 方法について分かったこと

説そのものより、こちらのほうが再利用できる。

**1. IS で見えた形は、2回とも OOS に残らなかった。**
#2 は山型が平らになり、#3 は単調な階段が逆さまになった。
**IS を判定に使わない設計が、2回とも正しかった。**
#6 では IS の水準すら見ずに封印し、OOS で一度だけ判定した。**形を見てから
決めるものが1つも無い状態でも、検証は成立する。**

**1-2. 封印前の検出力計算は、判定でそのまま再現した。**
#6 で 2001–2020 の分散から求めた標準誤差 0.43% に対し、OOS の実測は 0.399%。
必要な差 0.85% に対し実測の 2×SE は 0.80%。**判定に使わない期間の分散から、
判定期間の検出力を当てられる。** 平均を見なければ検定を消費しないので、
これは次の説でも最初にやってよい。

**2. 件数を先に数えると、無駄な封印を防げる。**
#1 は事前登録を書き上げてから実装し、最後に件数を測って「検証不能」で
終わった。#2 以降は順序を逆にして、**リターンを計算しない件数センサスを
先に走らせている**。#3 ではこれを3往復した（母集団 → 並べ替える変数の選択
→ 入場条件ごとの残存）。

**3. 説明のつかない数字を、根拠に使わない。**
検出力の1回目は「必要な差 3.94%」というもっともらしい結論を出した。入力の
日次SD 24.42% が、1分位162銘柄という母集団から説明できないことに気付いて
初めて、分割・併合の調整漏れが見つかった。除外後は 3.64%。**「桁が合わない」
は、それ自体が所見である。**

**3-2. 疑うときは、疑う対象を取り違えない。**
上の追跡で、材料（銘柄日ごとのリターン）ばかり2回見た。材料は最初から正常
だった。分散が付いているのは**分位平均そのもの**で、そこを見たのは3回目
だった。**「何の分散か」を先に言葉にする。**

**3-3. 止めるより、出して理由を併記する。**
汚染された分散から数字を出すまいとして、コマンドを止まるようにした。その
せいで「除外が効いたかどうか」を測る手段まで失った。保留は情報をゼロしか
生まない。

**4. 「片方の経路で無理」は「どこでも無理」ではない。**
立花のマスタに廃止銘柄が無いと分かった時点で、生存バイアスを恒久的な制約と
書いた。同じ日に J-Quants を測ったら取れた。**1つの情報源で詰まったら、
制約として書き残す前に、もう1つ測る。**

**5. 「マニュアルに項目がある」ことと「値が入っている」ことは別。**
J-Quants では推測した項目名だけを並べて、決算期末日が1件も入らないまま
気付かなかった。立花では上場廃止日が「項目はあるが 4,441 件中 4,418 件が空」
だった。**実装の前にプローブで件数を数える。**

**6. このプロジェクトで繰り返し起きるのは「例外で落ちる誤り」ではなく
「もっともらしいが違う値が黙って出る」誤りである。**
検証の過程で見つかった無言の欠陥（一部）:

- 流動性フィルタが1件も除外していなかった（#1）
- 開示時刻を保存しておらず、8割のイベントの反応日が1日ずれるところだった
- ベンチマークの窓が銘柄側より一晩長かった
- 表の「差」の列が、その内訳の列から復元できなかった（加重が違った）
- 銘柄一覧で7件が数えられずに落ちていた（原因は優先株の5桁コード。落ちるのは
  正しかったが、**数えていなかったので原因を推測するしかなかった**）
- レート制限（429）が銘柄ごとの失敗に化けていた。廃止銘柄399件の取り込みで
  **315件が2分で「失敗」し、そのどれ1つも実際には取りに行っていなかった**。
  財務側には対策が入っていたが、価格側は別経路で、そこだけ素通りしていた
- リバーサルの日次SD 24.42% が、分割・併合の調整漏れ数件でできていた
- ロングオンリーの主要指標（分位1 − ベンチマーク）が、効果と「等金額 対
  時価総額加重」を混ぜて測っていた（#6。判定は変わらなかったが、差の大半は
  並べ替えと無関係だった）
- 名簿の延べ銘柄数を、取り込みが 4,097 と報告し、ディスク上の実際は 4,124
  だった。**「その実行で要求した日付」しか数えていなかった。** 差の27銘柄は
  株価を取りに行く対象からも漏れていた（同じ量に2つの数え方があった）

## 8. 増担保規制の発動後ドリフト — **封印せず（§0 で止めた）**

**規制が掛かれば強制的に売らされる人が出る**——だからその後に下がるはずだ、
という説である。**機構がはっきりしている**ぶん、7本の失敗の後に残った最後の
候補だった。

### 何を測ったか（2026-09-16）

原本（`/markets/margin-alert`、2008-05〜2026-09）から発動を拾い、貸借銘柄・
流動性で絞り、**公表日の翌営業日の寄付きから14営業日**の超過リターンを、
**IS（2017-07-25 まで）だけ**で測った。

| | |
|---|---|
| 発動イベント | 1,414 件 → 貸借で 418 → 流動性で **409** |
| IS / OOS | **219 / 190** |
| 保有窓 | **14営業日**（解除までの中央値。式から出る） |
| 1イベントあたりのSD | **31.15%** |
| 検出できる差 | **1イベント 6.41%** |
| IS の取り高（ショート・費用引き後） | **1イベント −1.44%** |

### 3つとも、同じ向きを指した

1. **符号が逆だった。** 増担保が掛かった銘柄は、14営業日で市場を **+1.04%
   上回っていた**
2. **測る前にコミットした線（1.2%）を下回った。** 片側95%の下限は **−4.75%**
3. **検出できない。** 線の大きさを検出するだけで **5,431 件＝242年**要る。
   手元の OOS は 190 件

### 心配していたのは件数だった。縛っていたのは散らばりだった

登録時に書いた心配は件数である（イベント型は件数が命）。実際 OOS 190 件は、
2026-09-05 に自分で出した「1,000 件以上」に1桁足りない。

**だが縛っていたのは SD のほうだった。** 1イベント 31.15% は #7（月次・分位の
α で 1.84%）と桁が違う。**増担保が掛かるのは大きく動いた直後の銘柄**なので、
その後の14営業日も大きく動く。**母集団の選び方が、そのまま分散を決めていた。**

**仮にイベントが 1,000 件あっても届かない。**

### 上がる説として拾い直さない

IS で +1.04% 上回ったことを「規制後は上がる」として拾わない。**両側で当たりを
狙えば、どちらに転んでも当たりになる**（#9 で同じ形を禁じた）。拾うなら別の
1本で、別の事前登録が要る。

**「増担保規制の後にドリフトは無い」とも言わない。** 測ったのは IS であって
判定ではない。**言えるのは封印しないことだけである。**

**判定は消費していない。**（詳細は [PREREG_MARGIN_JP.md](PREREG_MARGIN_JP.md)

## 9. 買いにくい相場は高い — **封印せず（§0 で止めた）**

**出典つきで登録した最初の1本である**（2026-09-16）。そして**ゲートで止めた
最初の1本**でもある（同日）。

### ひとことで言うと

**割安な株は割安のまま放置される、という格言を PBR で測った。** IS（2009年〜
2017年）で出たのは**逆向き**で、割安な側が割高な側を年 14.9% 上回っていた。

**そこで止めた。** 測る前に「年 1.0% を下回ったら封印しない」と書いてコミット
してあり、下回るどころか向きが逆だったからである。

**「格言は外れたが、バリュー効果を見つけた」とは言わない。** それも封印より前に
禁じてある。両側で当たりを狙えば、どちらに転んでも当たりになる。

そして**向きをひっくり返しても、この設計では判定できない。** 月ごとの散らばりが
大きすぎて（SD 4.93%／月）、8.7年では見分けがつかない。IS で出た大きさがその
まま続いたとしても **16年**要る。**7.3年足りない。**

**判定は消費していない。**（詳細は
[PREREG_ANTIVALUE_JP.md](PREREG_ANTIVALUE_JP.md) §0 と §13）

### 出典

日本証券業協会「株式投資の格言」より
[買いにくい相場は高い](https://www.jsda.or.jp/start/proverb/contents/proverb26.html)
（2026-09-16 閲覧）。

主張の中心はここである。

> 安いからというただそれだけの理由で、株式を買う人がいる。…**株価が安いところ
> に置かれているのには、それなりの事情がある。** 事業そのものの見通しが立たず、
> 業績推移が思わしくない、元来が人気のつきにくいものである等の理由だ。
> したがって、**安値はいつまでたっても安値のままで放置される**ことになる。

> そうした理由も考えずに、**ただ単に高いということだけで敬遠していては、
> せっかくの相場にも乗れない**というわけだ。

> **「割り高に売りなし、割り安に買いなし」**と、**値ごろ感や単なる利回り採算
> だけで判定する誤りを戒めている。**

> 売りがたきところが下がり、買いがたきところが上がると知るべし。（相庭高下伝）

### 何を主張しているか

**世間の常識と逆向きである。** 「割安を買え」ではなく「割安は割安のまま」と
言っている。断面で並べたとき、**割高な側が割安な側を上回る**という予測になる。

### 「安い」の読みは **PBR（倍率）に決めた**（2026-09-16）

株価の水準ではなく倍率で回す。**値ごろ感で回すなら、それは別の1本である。**
種類のタグは `fundamental` になった。

### なぜ2通りに読めたか

| 読み方 | 何で並べるか | 種類 |
|---|---|---|
| **値ごろ感** | **株価の水準そのもの**（低位株、安値圏） | `technical` |
| **利回り採算** | **PBR・PER・配当利回り**（倍率） | `fundamental` |

**本文は両方に触れている。** 「株価が安いところに置かれている」は前者、
「割り高に売りなし、割り安に買いなし」「利回り採算」は後者である。

**どちらで回すかを先に決めないと封印できない。** 決めずに両方回せば、結果を
見てから通ったほうを採れてしまう。**それは判定ではない。** だから先に決めた。

**両方やるなら2本である**（`docs/PURPOSE.md` の数え方）。予算は残り15本。

### 既存の説と重なっていないか

- **#6 短期リバーサル**は数日〜数週の値動きで並べる。**倍率でも株価水準でも
  ないので、別の説である。**
- **#7 低ボラティリティ**は値動きの大きさで並べる。同じく別。

**重なっていない。** ただし「人の行く裏に道あり花の山」を別途登録すると #6 と
重なる恐れがあるので、そちらは注意すること。

### 手元のデータで何ができるか

| 読み方 | 使える期間 | 根拠 |
|---|---|---|
| 値ごろ感（株価水準） | **2001年〜**（立花） | 価格だけで済む |
| 倍率（PBR） | **2009年〜** | `bps`/`pbr` が 92% 以上埋まるのは 2009年から |
| 倍率（PER） | **2012年〜** | `eps`/`per` は 2011年以前が実質ゼロ |

**`market_cap` は百万円単位である。** 円として使うと百万倍間違える
（`CLAUDE.md`）。

### §0 の見通し

**見込み値の梯子は2段目になる。** 同じ設計で報告された文献値を持っていない
（格言に数字は無い）ので、**自分の IS から推定する。**

**必要な `t` は 3.02**（予算20本）。月次・断面の分位差なら観測は月単位で
150〜200 期あり、暦のアノマリーよりは桁が多い。**通る見込みはあるが、
やってみないと分からない。**

## 10. バリュー（低PBR を買う）— **封印せず（IS が設計で 2.8倍振れた。2026-09-17）**

### 結末（先に）

**同じ IS を測り方を変えて出したら、`t` が +2.15 から +0.76 まで振れた。**
2.8倍である。通る確率に直すと **16% 〜 1%**。

**「通る確率がいちばん高い説を回してみたい」という問いから始めて、ここに来た。**
いちばん高く見えていた数字（22%）は、**どの設計を選ぶかで作れる数字だった。**

**判定は消費していない。**

### 何を測ったか

同じ IS（2009-01〜2017-12、106ヶ月）のバリューを、**universe と推定量を1つずつ
動かして**測った（`research\バリューの食い違い.bat`、2026-09-17、`4835bd3`）。

**表はすべて費用引き前にそろえてある**（費用は月 0.064%、年 0.76%）。

| universe | 生のスプレッド | α（β を引く） | 横の差 |
|---|---|---|---|
| #9 の経路（PBR ファイル＋名簿） | **+2.15** | +1.83 | −0.32 |
| 盤面（低ボラ＋バリュー） | +1.19 | **+0.76** | −0.43 |
| 盤面（バリューだけ） | +1.21 | +0.84 | −0.37 |
| **縦の差** | **−0.96** | **−1.07** | |

**両方動いた。** 読み方は測る前に決めてあった——**両方動くなら、効果は設計の
選び方に対して頑健でない。それ自体が効果に対する反証寄りの情報である。**

### 低ボラの履歴要求は、原因ではなかった

盤面の2行がほぼ同じである（+1.19 対 +1.21、+0.76 対 +0.84）。**250営業日の
履歴を要求しても、しなくても変わらない。**

**では universe の何が効いているのかは、まだ特定できていない。** 残る違いは
名簿（生存）・不連続フィルタ（±50%）・入退場の取り方である。**確かめていない。**

### 検算の「期待値」を書き間違えていた

`#9 の +2.26` を再現の目標に置いたが、**あれは格言の向き**（高PBR − 低PBR）の
`t` である。バリュー向きに反転すると**費用が逆向きの引き算になり**、平均だけ
`2×費用` ぶん小さくなる（SD は動かない）。**期待値は +2.03** で、実測も +2.03
だった。**再現は成功していて、比べる相手のほうが間違っていた。**

### 言えること・言えないこと

- **言える。** この IS では、**バリューの `t` は測り方で 2.8倍振れる**
- **言えない。** 「バリューは効かない」とは言わない。**振れることと、無いことは
  別である**
- **言えない。** どの測り方が「正しい」とも言わない。**どれも事前に決めれば
  正当な設計である。だから封印前に1つに決める必要があった——決められなかった**

### 封印しない理由

**振れ幅の中から1つ選んで封印すれば、選んだこと自体が結果を作る。** 22% を
選ぶことも 1% を選ぶこともできてしまう。**それは判定ではない。**

**いま再設計する予定は無い。**

## 11. 低ボラ × バリュー — **封印せず（§0 で止めた）**

**複合型の1本目である。** 構成要素は #7（`technical`）と #10（`fundamental`）
で、**種類をまたぐ。**

### なぜこの組か

**2026-09-05 に束ねた3本は、3本とも `technical` だった。** 合成 t −0.14、
最良の単独 +1.69 で符号が逆になり、因子探索はそこで閉じた。**その束には
`fundamental` が1本も入っていない。**

**閉じた結末は動かさない。** ここで測るのは `composite-gain` の r ではなく、
**複合型それ自体**である。r には「曖昧域で財務系の再測定はしない」と測る前から
書いてあり、そこには触らない。

### 封印前に決めてコミットしたこと（2026-09-16）

- **IS で試すのは1通りだけ**（等加重の z スコア合算）。重みは動かさない。
  **2通り目を回したくなったら封印しない**
- **封印しない線は「実測した往復費用の3倍」。** 数字ではなく規則で置いた——
  費用は入れ替わり率で決まり、それは測るまで分からないので、「年 X%」と
  決め打つと X の出どころを書けない。3倍にするのは #8 と同じ理由で、費用を
  超えるだけの線では #7 が入った帯にまっすぐ入るからである
- **合格には最良の構成要素単独を上回ることが要る**（PURPOSE の複合型ルール）
- **脚には判定を出さない。** 累計に数えるのは、この複合 **1本**だけ

### 気を付ける場所（**当たらなかった**）

登録した時点で危ないと書いたのは件数だった——バリューを足すと `pbr` の無い
銘柄月が落ちて断面が痩せ、分位が効かなくなる、と。

**実際は 1,011 対 1,067 で、減りは 5% しかなかった。** 月数も 106 対 106。
**書いた心配は当たらず、落ちたのは別の場所である。**

### 結末（2026-09-16）— §0 で止めた

**散らばりが大きすぎた。** 合成スプレッドの α は SD 4.46%／月で、104ヶ月・
`t ≥ 3.02` で検出できる差は **年 15.0%**。IS の見込みは 年 −7.5% 〜 +11.8% で、
**上限すら届かない。** 回しても不合格にしかならない。

上限どおりの効果（年 11.8%）を検出するだけでも **14年**要る。手元の OOS は
**8.7年**で、**5.5年足りない。**

そして「最良の単独を上回る」ほうも、IS では満たしていない。

| | IS の t（α、同じ盤面・同じ月） |
|---|---|
| **合成** | **+0.43** |
| バリュー（#10） | +0.76 |
| 低ボラ（#7） | +0.42 |

**判定は消費していない。**

### 2026-09-05 の結論は、`technical` に限った話ではなかった

因子探索を閉じたとき、束ねた3本は3本とも `technical` だった。**`fundamental`
を1本入れれば違うかもしれない**——それが #11 を登録した理由である。

**違わなかった。** 符号こそ逆転しなかったが、**合成は最良の単独を下回った。**

**「因子を束ねる」という手は、種類をまたいでも利得が出ない。**

**「低ボラ × バリューは効かない」とは言わない。** 測ったのは IS であって判定
ではない。言えるのは封印しないことだけである。（詳細は
[PREREG_LOWVOL_VALUE_JP.md](PREREG_LOWVOL_VALUE_JP.md) §0 と §13）
