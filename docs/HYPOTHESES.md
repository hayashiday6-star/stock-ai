## 1. アキュムレーション5条件 — 中止（検証不能）

### 何を調べようとしたか

「静かに下げてきた低位株に、ある日ふつうの5倍の出来高が入る」——
それを買えば、その後20営業日で市場平均を上回るのではないか。

### なぜ閉じたか

**現象そのものは 11,014 件見つかった。問題は、その 97.5% が「自分が売買
できない銘柄」で起きていたことである。**

| 段階 | 残った件数 |
|---|---|
| 5条件を満たすスパイク | 11,014 |
| ＋ 普段から1億円の商いがある銘柄に限る | **279**（−97.5%） |
| ＋ 決算や権利落ちなど材料のある日を除く | **68** |

事前登録は「OOS で100件以上」を要求していた。68件では**リターンを計算する
前の段階で条件に届かない**ので、そこで打ち切った。

言い換えると:

> **この5条件が拾う現象と、自分が売買できる銘柄の範囲が、ほとんど交わって
> いなかった。** 「静かな低位株の出来高スパイク」は、そもそも小型で
> 商いの薄い銘柄で起きることだった。

### 当初の見立てが外れた点

打ち切りの筋書きとして「出来高5倍は決算発表日の出来高を拾っているだけでは
ないか」を想定していた。**実測は違った。** 流動性のある279件のうち、材料日の
内訳は **権利落ち関連 95件 に対して決算 31件** で、権利確定に伴う売買のほうが
決算の3倍多かった。

### この件で見つかった実装の欠陥

流動性フィルタを「スパイク当日の売買代金」で判定していたとき、**除外は
0件だった**。出来高が5倍になっていれば、それだけで1億円を超えてしまう。
**効いていないフィルタが、効いているように見えていた。**
20日平均に直したのは「厳しくした」のではなく、**初めて効かせた**ことになる。

## 2. 決算後ドリフト（株価反応で並べる）— 不合格

### 何を調べようとしたか

決算発表の日に大きく上がった銘柄は、その後60営業日も上がり続ける。
下げた銘柄は下げ続ける。この差を取れば儲かるのではないか。

### なぜ閉じたか

**IS（練習期間）で弱く出た効果が、OOS（本番期間）で符号ごと反転した。**

| | IS 2021-2023 | OOS 2024-2026 |
|---|---|---|
| 上位分位 − 下位分位 | +1.10% | **−0.78%** |
| t値 | 0.81 | −0.82 |

事前登録は「OOS でプラス」「IS の半分以上」「t ≥ 2.0」の3つを全部満たすこと
を求めていた。**3つとも満たさなかった。**

分位の階段も再現しなかった。IS では山型に見えたものが、OOS ではほぼ平らに
なった（振れ幅 2.68pt → 0.29pt）。**形に見えたものは揺らぎだった。**

## 3. 決算後ドリフト（会社予想との差で並べる）— 不合格

### 何を調べようとしたか

#2 と同じ現象を、**別のものさし**で測り直した。「発表日にどれだけ株価が
動いたか」ではなく「**会社が出していた予想を、実績がどれだけ上回ったか**」
で並べ替える。

#2 の不合格が「ドリフトが無い」せいなのか「並べ方が悪かった」せいなのかを
分けるための追試であって、新しい説ではない。**セクション3-3（並べ替える
変数）以外は、#2 の封印文書からそのまま写した。**

### なぜ閉じたか

**IS ではこの検証で最も良い形が出た。それが OOS で反転した。**

| | IS 2021-2023 | OOS 2024-2026 | 併合 |
|---|---|---|---|
| 上位分位 − 下位分位 | **+3.51%** | **−3.02%** | **−0.29%** |
| t値 | 1.48 | −1.77 | −0.20 |

IS では分位の階段が**単調**だった（−0.98 / +0.55 / +1.22 / +1.29 / +1.64）。
差は両端の2点しか使わないので、単調性のほうが強い証拠になる。

OOS ではその階段が**逆さま**になった（+3.47 / +0.81 / +1.58 / +1.19 / −0.06）。
**会社予想を最も下回った銘柄が、その後いちばん上がっていた。**

IS と OOS を合わせると **−0.29%（t = −0.20）** で、実質ゼロである。
符号が逆で、大きさがほぼ同じで、どちらも有意でない——
**同じ分布から2回引いた2つの数字として自然な形。**

### 主張できないこと（重要）

**「決算ドリフトは存在しない」とは言えない。** 言えるのは次までである。

- この検証が検出できるのは **+3.7〜4.2% 以上**。それ未満の効果があっても
  見えない
- 驚きが大きいのは**小型株に偏る**が、売買代金1億円のフィルタでその大半が
  落ちている。**現象が住んでいる場所を、この検証は測っていない可能性がある**
- 通期決算の短信は、実績と**同時に翌期の予想も出す**。手計算した6件のうち
  3件で、実績の驚きと当日の株価反応の符号が逆だった。
  例: トヨタ 2022-05-11 は前期実績を予想より14.5%上回りながら、資材高で翌期の
  減益を見通したため、その日の市場対比は −3.7% だった。**「実績の驚き」と「その日の新情報」は
  別のものである**

## 4. 決算集中日の注意分散 — 判定せず

### 何を調べようとしたか

決算発表が集中する日は投資家の注意が分散するので、ドリフトが**大きくなる**
のではないか。#2 の副仮説として登録した。

### なぜ判定しなかったか

事前登録が「**主仮説が不合格なら副仮説は判定しない**」と定めていたため。
ドリフトそのものが無いなら、その大小を比べる意味がない。

記録だけ残す。OOS の混雑日は +1.57%（t=1.75）だった。**これは判定ではない。**

## 5. 予想修正後のドリフト — 設計やり直しが必要

### 何を調べようとしたか

会社が業績予想を上方修正した後、株価は上がり続けるのではないか。
「決算日とは独立したイベント」として設計するつもりだった。

### なぜ止まっているか

**前提が成り立たないことが、実装の途中で分かった。**

予想修正は**独立した開示として取得できない**。実測で `fins/summary` が返す
開示の 99.2% は決算短信で、予想修正は上位12種類に1件も現れなかった。

したがって修正を知る唯一の経路は、**決算短信に毎回載る通期予想を、前回の
短信と突き合わせること**になる。その帰結が3つある。

1. **イベント日が決算発表日と重なる。** 「決算とは独立」という前提が崩れる
2. **最大3ヶ月遅れる。** 会社が5月に上方修正しても、こちらが知るのは8月の
   短信を前期と比べたときになる
3. **同じ日付を3度目に使うことになる。** #2 と #3 で落とした日付・銘柄・
   60営業日リターンと、ほぼ同じ集合を再利用することになる

3番目が重い。このまま回すのは、名前を変えた**3つ目の操作化**であり、
「決算ドリフトのテーマを閉じる」という判断と矛盾する。

### 分かっていること（やり直すときの材料）

`revision-census` を回すと、短信どうしの突き合わせで検出できる修正の件数が
出る。実行時（2026-09-03）は約7,500件・年1,650件程度だった。

**ただしこの数字はどの事前登録にも記録していない。** 会話の中で1度出しただけ
なので、やり直すときは `research\予想修正センサス.bat` を回し直して確定させること。
**出典の無い数字を設計の根拠にしない。**

## 6. 短期リバーサル — 次にやる

### 何を調べるか

短期間に大きく下げた銘柄は反発する。

### なぜこれを次にするか

- **価格データだけで検証できる。** 財務も開示時刻も要らない
- **イベント日が決算日と無関係。** #2 と #3 で使い切った日付集合と重ならない
- J-Quants を解約してもデータが途切れない

### 封印前に片付いていること・残っていること

| 論点 | 状態 |
|---|---|
| 母集団の件数 | 済。6,245営業日、中央値 968銘柄/日、薄い日は1日だけ |
| 分位ごとの規模の偏り | 済。売買代金は5分位で 4.7〜5.2 億円と**平らだった**（小型に寄るという事前の見立ては外れ） |
| 空売りの可否 | 済。貸借銘柄は 60.1%、しかも `sSinyouC` は現在値なので過去に当てると先読み。**主要指標はロングオンリー（分位1 − ベンチマーク）にする** |
| 生存バイアス | **作業に変わった。** 上記のとおり解約前に名簿と株価を落とす |
| 判定期間 | **決定。2021-09 以降。** 理由は下記 |
| 検出力の事前計算 | **1回目の結果が信用できない。** 下記 |
| 生存バイアスの実測 | **未実施。** `research\生存バイアスの大きさ.bat`。取り込み後、IS でのみ |

### 検出力の1回目（2026-09-04）— 数字は出たが、採らない

2001-2020（4,765営業日、中央値812銘柄/日）から出た値。

| 指標 | 日次SD | 重なりの膨張 | OOS(630日)の標準誤差 | t≥2.0 に必要な差 |
|---|---|---|---|---|
| 分位1 − ベンチ（主要） | 24.42% | 2.02x | 1.97% | **3.94%** |
| 分位1 − 分位5（副次） | 24.53% | 1.98x | 1.94% | 3.87% |

**この 24.42% が説明できない。** 1分位に約160銘柄入るので、個別のばらつきが
そのまま残ることはあり得ない。160件の平均は個別のおよそ 1/13 になるはずで、
個別の20日リターンのSDが仮に15%でも、平均のSDは1〜2%＋共通要因ぶんに収まる。

SUE 版の 21.08% は1分位1〜2銘柄で説明がついた。**ここは約160銘柄あるのに
同じ桁が出ている。説明がつかない数字を根拠に判定期間を決めない。**

疑うのは分割・併合の調整漏れである。1:10 の併合を調整せずに持つと +900% に
なり、160銘柄の分位でも1件で平均が +5.6% 動く。`docs/CLAUDE.md` が挙げている
「分割前後で尺度の違う値を組み合わせる」形そのもの。

`research\リバーサル検出力.bat` に、銘柄日ごとのリターンの分位と、絶対値の
大きい銘柄日の一覧（銘柄・日付つき）を出すようにした。**もう一度回して、
24.42% が何でできているかを見てから、必要な差を決める。**

### 判定期間を 2021-09 以降にした理由（2026-09-03 決定）

長い期間（2001年〜）を主要指標にすれば検出力は稼げる。それを採らない。

**1. 2001-2020 の生存バイアスは、今後どれだけ時間をかけても直せない。**
廃止銘柄の株価も 2021-09 以降しか取れない（実測で 1352 も 1737 も 2022年
までしか返らない）。「いまは直せない」ではなく「永久に直せない」。長い期間を
主要指標に置けば、その汚染は最後まで残る。

**2. この説では、バイアスが処置群そのものに乗る。**
買うのは直近の下落率上位である。廃止される銘柄が最も濃く集まる場所が、
まさに分位1になる。全体に薄く乗る誤差ではない。

**3. 符号が分からないので、事後の補正もできない。**
TOB・完全子会社化はプレミアム付きで消え、破綻はゼロになる。向きが決まらない
ぶん、「多少楽観側に出る」という程度の話にならない。**結果の大部分が説明の
つかない要因でできている可能性がある**、という話になる。

**4. 折衷案（長期を主要・クリーンを副次）には、良い答えが存在しない。**
長期が合格でクリーンが不合格のとき、合格と書けない。書けないなら主要指標は
副次に従属しており、それは副次が主要だということである。逆に一致するなら、
短い期間で得られる結論を、汚染された指標を経由して得ただけになる。
**上振れの余地しかない設計になる。**

**5. 失敗の形が非対称である。**
短い期間で失敗すると偽陰性——効果があるのに検出できず、見送る。長い期間で
失敗すると偽陽性——汚染由来の合格を本物と信じ、実際に資金を入れる。
**副収入を作るのが目的である以上、この2つは等価ではない。**

代償ははっきりしている。センサスが見つけた 6,245 営業日のうち、判定に使える
のは 2021-09 以降だけになる。**2001-2020 は分散の推定にしか使わない**
（平均は見ない。分散の推定は仮説検定を消費しない）。

### 生存バイアス — 恒久的な制約ではなく、期限つきの作業だった

2026-09-03 まで、すべての事前登録に「上場廃止銘柄が入っていない」と書いてきた。
立花の銘柄マスタは現存銘柄しか返さないので、そこで詰まったと判断していた。

同じ日に測り直して、**J-Quants からなら取れる**ことが分かった
（`checks\生存バイアス確認.bat`）。

- 日付ごとの上場一覧が返る。**名簿同士の差＝その期間に消えた銘柄**で、
  年 49〜106 件、しかも年々増えている（2021-10→2022-06 が 49、
  2024-06→2025-06 が 106）
- 消えた銘柄の**株価も 5/5 で取れた**。銘柄コードだけでは何もできないので、
  ここが本題だった

したがって制約は次の2つに変わる。**どちらも後から緩められない。**

- **2021-09 より前は直せない。** J-Quants の5年ローリング窓の外で、
  いま実行しても返らない
- **2026-09-22 を過ぎると、二度と取れない。** 名簿も、廃止銘柄の株価も

作業は `checks\廃止銘柄の取り込み.bat`（`stock-ai delisted-harvest`）。
名簿は `data/universe_snapshots/` に**日付ごと**に保存する。和集合ではない。
和集合しか持たないと、2023年に上場した会社を2021年の分位に入れられてしまい、
生存バイアスを直したつもりで先読みを持ち込むことになる。

**#6 短期リバーサルは、この作業が終わってから封印する。** 下げた銘柄を買う
戦略にとって、下げて消えた銘柄が丸ごと欠けたデータは但し書きでは済まない。
ただし判定期間を 2021-09 以降に寄せると、いま持っている 6,245 営業日の履歴の
大半が判定に使えなくなる。**この取引をどう決めるかは、封印前に決着させる。**

## 方法について分かったこと

説そのものより、こちらのほうが再利用できる。

**1. IS で見えた形は、2回とも OOS に残らなかった。**
#2 は山型が平らになり、#3 は単調な階段が逆さまになった。
**IS を判定に使わない設計が、2回とも正しかった。**

**2. 件数を先に数えると、無駄な封印を防げる。**
#1 は事前登録を書き上げてから実装し、最後に件数を測って「検証不能」で
終わった。#2 以降は順序を逆にして、**リターンを計算しない件数センサスを
先に走らせている**。#3 ではこれを3往復した（母集団 → 並べ替える変数の選択
→ 入場条件ごとの残存）。

**3. 「片方の経路で無理」は「どこでも無理」ではない。**
立花のマスタに廃止銘柄が無いと分かった時点で、生存バイアスを恒久的な制約と
書いた。同じ日に J-Quants を測ったら取れた。**1つの情報源で詰まったら、
制約として書き残す前に、もう1つ測る。**

**4. 「マニュアルに項目がある」ことと「値が入っている」ことは別。**
J-Quants では推測した項目名だけを並べて、決算期末日が1件も入らないまま
気付かなかった。立花では上場廃止日が「項目はあるが 4,441 件中 4,418 件が空」
だった。**実装の前にプローブで件数を数える。**

**5. このプロジェクトで繰り返し起きるのは「例外で落ちる誤り」ではなく
「もっともらしいが違う値が黙って出る」誤りである。**
検証の過程で見つかった無言の欠陥（一部）:

- 流動性フィルタが1件も除外していなかった（#1）
- 開示時刻を保存しておらず、8割のイベントの反応日が1日ずれるところだった
- ベンチマークの窓が銘柄側より一晩長かった
- 表の「差」の列が、その内訳の列から復元できなかった（加重が違った）
- 銘柄一覧で7件が数えられずに落ちていた（原因は優先株の5桁コード。落ちるのは
  正しかったが、**数えていなかったので原因を推測するしかなかった**）

## この文書の更新について

- **説の状態が変わったら、ここを直す。** 事前登録だけを直して一覧を放置すると、
  どちらが本当か分からなくなる
- 閉じた説は**消さない**。「何を試したか」は「何が残っているか」と同じくらい
  重要である
- 閉じた理由は**専門用語なしで**書く。半年後の自分が読んで分かること
- 数字は事前登録から引き写す。**ここで計算し直さない**（二重管理になる）
