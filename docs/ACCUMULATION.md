# アキュムレーション検出 (`stock-ai accumulation`)

米国株から「機関投資家が静かに仕込んでいる形」を、3フェーズで探します。

```powershell
# 銘柄を並べて試す（まずはこれ。ファイルは要りません）
uv run stock-ai accumulation AAPL MSFT NVDA AMD INTC

# 手持ちのリストから（1行1銘柄、# でコメント可）
uv run stock-ai accumulation --symbols-file us.txt

# 全市場（NASDAQ Trader の上場ファイルを取得。数分かかります）
uv run stock-ai accumulation

# 条件を緩めて回す
uv run stock-ai accumulation AAPL MSFT --volume-multiple 3 --max-range 0.15
```

**前提**: 株価は yfinance、資金フローは moomoo OpenD から取ります。OpenD が
起動・ログイン済みであることを `moomoo接続確認.bat` で先に確認してください。

---

## 何を見ているか

| フェーズ | 内容 |
|---|---|
| 1 | 全市場を株価・出来高・52週安値比・20日レンジで絞る（上位10件） |
| 2 | 上位5件に資金フロー・空売り・テクニカルを当て、完了度を7条件で採点 |
| 3 | 完了度の高い銘柄にブレイクアウト5条件を当て、n/5 と撤退ラインを出す |

処理の順番が設計そのものです。株価と出来高は1回の一括ダウンロードで全銘柄
分が取れて1銘柄あたりの費用はゼロですが、**時価総額は1銘柄1リクエスト**、
**資金フローは30秒に30回**が上限です。高い質問は、安い質問を通過した銘柄に
しかしません。

### 緩和ラダー

原条件で0件のとき、以下を**累積で**適用し、必ず結果を出します。適用レベルは
レポート冒頭に必ず表示されます。

1. 出来高3倍以上
2. 時価総額1億ドル以上
3. 52週安値+20%以内
4. レンジ15%以内

**レベル④の結果とレベル⓪の結果は別物です。** 緩めた末に出てきた銘柄を、
厳しい条件を通った銘柄と同じ重みで読まないでください。

## 取得できるもの・できないもの

このコマンドは**推定値で穴を埋めません**。取れないものは理由付きで
「取得不可」または「未実装」と表示します。

| 項目 | 状態 | 理由 |
|---|---|---|
| 株価・出来高・52週安値・20日レンジ | ✅ | yfinance |
| 時価総額・セクター・次回決算日 | ✅ | yfinance |
| Large / Medium / Small NetIn（10日） | ✅ | moomoo（Large = 特大口＋大口） |
| BB幅・SMA乖離・RSI・MACD・OBV・A/D・VWAP | ✅ | 自前計算 |
| Short Interest・Days to Cover | ⚠️ | yfinance。月2回・遅延あり |
| 直近2回の空売り増減 | ⚠️ | 公開は直近2時点のみ。増減は**1回分しか出せません** |
| **大口比率（Large ÷ 全体出来高）** | ❌ 取得不可 | moomoo は**金額ベースの純流入**のみ。出来高比は形成不能 |
| 寄付き30分／引け30分の大口偏り | ❌ 取得不可 | moomoo の INTRADAY は**当日のみ**。過去10日分は提供されない |
| プレ／アフター異常出来高 | ❌ 取得不可 | moomoo は場中データのみ |
| ダークプール比率 DPI | ❌ 取得不可 | FINRA ATS（週次・遅延）か有料フィードが必要 |
| ブロック取引（1万株超） | ❌ 取得不可 | 約定単位のティックデータが必要 |
| 借株コスト Borrow Fee | ❌ 取得不可 | ブローカー／有料フィードのみ |
| 13F・13D/13G | ⏳ 未実装 | SEC EDGAR から取得可能。四半期・最大45日遅延 |
| Form 4（インサイダー） | ⏳ 未実装 | SEC EDGAR から取得可能 |
| 8-K・格付変更・主要報道 | ⏳ 未実装 | EDGAR / ニュースフィード |

### 完了度7条件目について

仕様の7条件目は「大口比率50%以上 **または** DPI 45%以上」ですが、上表のとおり
**両方とも取得できません**。この条件は常に「判定不可」になります。

そのため完了度は2通り出します。

- **仕様どおりの7条件で算出した %**（判定不可は未達扱い＝最大 85.7%）
- **判定できた条件だけで算出した %**（参考値）

判定不可は「大口が入っていない」という意味では**ありません**。測っていない、
という意味です。混同すると、測れないだけの銘柄を除外してしまいます。

## 毎日実行して Discord に通知する

**`アキュムレーション日次.bat` をダブルクリック**し、メニューから選びます。

```
1 = 今すぐ実行、コンソールに出すだけ（まず動作確認に）
2 = 今すぐ実行して Discord に送る
3 = 毎日 07:00 に実行するよう登録
4 = 同上、該当0件の日も送る
```

PowerShell から直接:

```powershell
.\scripts\7-accumulation-daily.ps1 -Channel console          # 送らずに文面だけ見る
.\scripts\7-accumulation-daily.ps1 -Register -At 07:00 -Channel discord
uv run stock-ai accumulation --channel discord                # CLI から単発で
```

事前に Discord の Webhook URL が必要です。

```powershell
.\scripts\set-key.ps1 DISCORD_WEBHOOK_URL
```

### なぜ 07:00 か

米国市場の通常取引は 16:00 ET に終わり、日足はその後に出ます。日本時間では
早朝にあたるため、07:00 は「米国の終値が出た後」に置いてあります。これより
早く回すと前営業日を読みます。日足が2営業日以上古い場合は、レポートと通知の
冒頭に警告が出ます。

### 0件の日は既定で送りません

このスクリーナーは0件の日のほうが多く、毎日「該当なし」が届く通知は2週間で
読まれなくなります。ただし**送らないと、静かな日と動いていないジョブが
スマホからは区別できません。** どちらの間違いを取るかなので、`-Heartbeat`
（メニューの4）で0件の日も送れるようにしてあります。

### 通知の中身

Discord は 2000 文字を超えると**本文ごと落とします**（切り詰めてはくれません）。
そのため文字数を計算して収め、入り切らない分は「…ほか N 件」と件数を出します。
並び順は A → B → C → D なので、削られるのは行動につながらない側からです。

```
**米国株 アキュムレーション検出** 2026-08-29
基準日 2026-08-28 ／ 緩和: 緩和なし（原条件） ／ 6,214 銘柄を測定

**ANF** Abercrombie & Fitch — C=仕込み継続中
　完了度 85.7% ／ 確定度 1/5 ／ Large10日 +30.00M
　安値比 +1.4% ／ 20日レンジ 2.6% ／ 出来高 5.94倍
　入 $20.51 ／ 撤退 $20.41 ／ 決算 ⚠️ 2026-09-02

_DPI・ブロック取引・借株コスト・大口比率は取得不可。推定値では埋めていません。_
```

**最後の1行は必ず入ります。** 通知は要約ですが、要約だからといって「測って
いない項目がある」ことまで省くと、完全な絵に見えてしまいます。

### 「決算 データ不足」が出たら

全市場スキャンの直後はプロファイル取得が絞られるため、通知にこう出ることが
あります。**その銘柄に決算予定日が無いのではなく、呼び出しが失敗しています。**
その場合は冒頭にこの1行が付きます。

```
⚠️ N 銘柄でプロファイル取得に失敗（セクター・空売り・決算日）。
データが無いのではなく呼び出しが失敗しています。
```

コマンド側では待って3回まで再試行しますが、待ち時間の総量は1回の実行あたり
90秒までに制限しています。全銘柄で絞られている実行が、同じ失敗のために5分
余計にかかるのは無意味だからです。上限に達した場合は理由にその旨が出ます。

埋めたい場合は、数分おいてその銘柄だけ実行し直してください。

```powershell
uv run stock-ai accumulation GAP
```

### 通知が失敗しても、スクリーニングの結果は残ります

Webhook が落ちていても終了コードは変えません。レポートは既に出力済みで、
配送の問題で成功した処理を捨てる理由が無いためです。失敗した旨は画面に出ます。

## 該当0件のとき

緩和ラダーを最後まで適用しても0件なら、**どの条件で何銘柄落ちたか**と、
**銘柄ごとの実測値**を出します。

```
どの条件で落ちたか（最も緩い条件で）
│ 出来高倍率 │ 5 / 5 │
│ 52週安値比 │ 5 / 5 │

銘柄ごとの実測値
│ AAPL │ 出来高倍率: 1.05倍 < 下限 3.0倍 / 52週安値比: +64.7% > 上限 +20% │
```

「該当なし」だけでは、**銘柄の形が合わなかったのか、条件が厳しすぎたのか、
価格データが取れていないのか**が区別できません。3つは対処が正反対なので、
判断した数字をそのまま出します。

なお、**このスクリーナーは高値圏の大型株では原理的に0件になります。**
探しているのは「52週安値の近くでレンジが締まっている」形なので、
AAPL や NVDA のような銘柄を入れても該当しません。銘柄が悪いのではなく、
探している形が違います。

## セクター・空売り・決算日がまとめて空欄になったら

全市場スキャンの直後は、株価は取れているのにこれらだけが欠けることがあります。
**取れないのではなく、プロファイル取得が絞られています**（数千銘柄を一括で
取った直後にレート制限に当たるため）。

レポート末尾の「取得に失敗した項目」に、プロバイダ側のメッセージがそのまま
出ます。`Rate limited` と書いてあれば、数分おいて対象銘柄だけを指定して
再実行すれば埋まります。

```powershell
uv run stock-ai accumulation GAP
```

コマンド側でも3回まで待って再試行しますが、全市場スキャン直後はそれでも
足りないことがあります。

## 読み方の注意

- **出来高倍率は判定当日を平均から除いて計算しています。** 当日を自分の平均に
  含めると、異常な日ほど平均が押し上げられ、真の5倍が4.2倍として出ます。
- **Large は特大口＋大口です。** moomoo の `main_in_flow` と一致することを実データ
  22営業日で確認していますが、公式に定義は無いため、こちらは `super_in_flow`
  と `big_in_flow` を直接足しています。
- **フェーズ3の④は「判定不可」になることがあります。** 上抜けが最新足のとき、
  翌日はまだ存在しません。未達にすると最も新しいシグナルが新しいという理由
  だけで減点されるため、判定不可としています。
- **時価総額が読めない銘柄は除外せず残します。** 除外すると「測って落ちた」の
  か「測れなかった」のか区別できなくなるためです。表に印が付きます。
- **日足が1営業日遅れていることがあります。** 出来高倍率は「最新足」で判定
  するため、2営業日以上遅れている場合は冒頭に警告を出します。
- **深掘りは上位5銘柄のみです。** moomoo のレート制限（30秒に30回）に収める
  ためで、6位以下の資金フロー欄は「未実装」ではなく理由付きで空欄になります。

## これは投資助言ではありません

数字を出すだけのツールです。判定区分（A〜D）は仕様どおりの機械的な分類で、
推奨ではありません。ダマシは日常的に起きるので、撤退ラインは必ず数値で決めて
から入ってください。
