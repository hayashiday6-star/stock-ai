## §0. 検出可能性ゲート（**最初に埋める。ここで落ちたら封印しない**）

### 封印しない線 — **測る前に置く**

> **IS で推定した合成の α が、実測した往復費用の 3 倍を下回ったら封印しない。**

**数字ではなく規則で置く。** 費用は入れ替わり率で決まり、入れ替わり率は測る
まで分からない。**「年 X%」と決め打つと、その X がどこから来たかを書けない。**

**3倍にするのは #8 と同じ理由である。** 費用を超えるだけの下限を置くと、#7 が
入った帯にまっすぐ入る。帯に入った判定は「無い」と「あると言い切れない」を
分けられないまま、**判定を1回消費する。**

### IS で試す組み合わせは **1通りだけ**（測る前に決めた）

> **等加重の z スコア合算、1通り。重みは動かさない。**

**予算20本の補正は、IS の中で何通り試したかを知らない。** IS で何通りも回して
最も良いものを封印すれば、補正はその試行を覆わないまま `t ≥ 3.02` を当てる
ことになる。`composite.Design.tries_in_is` がこの数を持ち、`composite-gate` が
超過を弾く。

**重みを外して回したくなったら、それは2通り目である。** そのときは封印しない。

### 見込みをどこから取るか — **段2（自分の IS から推定する）**

**段1は使えない。** この組を報告した文献値を持っていない。

段2の条件3つ。

1. **上の「費用の3倍」を、測る前に書いてコミットした。** ✅
2. **IS と OOS は1日も重ねない。** §6 で日付を固定する ✅
3. **検出できる差は OOS の期数（104）で計算する。** 全期間ではない ✅

## §1. 仮説

**低ボラと低PBR を両方満たす銘柄群が、どちらか一方だけの銘柄群を上回る。**

### 合格には「最良の構成要素単独を上回る」ことが要る

`docs/PURPOSE.md` の複合型ルール4である。**合成の α が正で `t ≥ 3.02` でも、
低ボラ単独のほうが良ければ不合格。** 束ねた意味が無いからである。

**最良は後から選ぶ。** そのぶん分母が大きくなり、判定は厳しく出る。
**その向きが安全な側である。**

### 脚には判定を出さない

`VALUE_JP`（#10）と `LOWVOL_JP`（#7）の数字は、**この判定の合格線として**
同じ盤面・同じ月で計算する。**それは脚の判定ではない。**

- #7 は 2026-09-05 に**別の期間**（2014-01〜2021-08）で判定済みである。ここで
  出る数字はその判定を上書きしない
- #10 は**まだ封印していない。** ここで出る数字を「#10 の判定」と読まない

**累計本数に数えるのは、この複合1本だけである。**

## §3. 並べ替えと分位

- 低ボラ … 日次リターンの標準偏差（250営業日）。**符号を反転**して「大きい

  すると上位の数銘柄が重みを独占する
- **月ごとに各因子を標準化してから、等加重で足す**（`Panel.composite`）
- 昇順に5分位。**差 ＝ 分位1 − 分位5**（合成 signal の大きい側 − 小さい側）

## §13. 判定（回した後に書く）

**回していない。判定は消費していない。** §0 で止めたからである。

### 何が起きたか（2026-09-16）

**散らばりが大きすぎた。** 合成スプレッドの α は SD 4.46%／月で、104ヶ月・
`t ≥ 3.02` で検出できる差は **年 15.0%**。IS の見込みは 年 −7.5% 〜 +11.8% で、
**上限すら届いていない。**

### 「最良の単独を上回る」も、IS では満たしていない

| | IS の t（α、同じ盤面・同じ月） |
|---|---|
| **合成** | **+0.43** |
| バリュー（#10） | +0.76 |
| 低ボラ（#7） | +0.42 |

**合成が、バリュー単独を下回っている。** 束ねた意味が無い形である。

**これは判定ではない。** 合格条件を当てるのは OOS で、そこには触れていない。
ただし §0 と合わせて、**同じ向きを指している。**

### 2026-09-05 と同じ形が、種類をまたいでも出た

因子探索を閉じたとき、束ねた3本は3本とも `technical` で、合成 t −0.14 に対し
最良の単独 +1.69 だった。**`fundamental` を1本入れれば違うかもしれない**——
それが #11 を登録した理由である。

**違わなかった。** 符号こそ逆転しなかったが、**合成は最良の単独を下回った。**

**「因子を束ねる」という手は、種類をまたいでも利得が出ない。** 2026-09-05 の
結論は、`technical` に限った話ではなかった。

### 断面が痩せたせいではない

事前に危ないと書いていたのは件数のほうだった（PBR を要求すると断面が痩せる）。
**実際は 1,011 対 1,067 で、減りは 5% しかない。** 月数も 106 対 106 で同じ。
**書いた心配は当たらず、落ちたのは別の場所である。**

### この数字について言えること・言えないこと

- **言える。** この設計・この期間では、**判定できる見込みが無い。** 上限を
  通すだけでも 14年要り、手元は 8.7年である
- **言えない。** 「低ボラ × バリューは効かない」とは**言わない。** 測ったのは
  IS で、判定ではない。言えるのは**封印しないことだけ**である
- **言えない。** #7 と #10 それぞれについては何も。**脚に判定は出さない**と
  封印前に決めてある（§1）
- **言えない。** OOS（2018-01〜2026-08）については何も。1日も読んでいない

### 再設計するなら、どこを変えるか

**期数は増やせない。** 変えるなら散らばりのほうだが、**月次の分位スプレッドは
この母集団で SD 4.5%／月前後**で、#9（生の差 4.93%）とほとんど変わらなかった。
**β を引いても縮まない**——ロングショートは元から β −0.25 しかない。

`docs/NEXT_CANDIDATES.md` が 2026-09-05 に出した結論と同じ場所に戻る。
**「もっと良い因子」ではなく、短い窓で独立なイベントが1,000件以上あるもの。**

**いま再設計する予定は無い。** 次に何をするかはユーザーが決める。
