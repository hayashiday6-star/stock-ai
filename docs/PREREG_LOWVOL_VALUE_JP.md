# 事前登録 — `LOWVOL_VALUE_JP`「低ボラ × バリュー」（日本株・複合型）

**状態：§0 を測る前。封印していない。**（2026-09-16）

**複合型の1本目である。** 構成要素は `LOWVOL_JP`（#7、`technical`）と
`VALUE_JP`（#10、`fundamental`）。**種類をまたぐ複合である。**

## なぜこの組か

**2026-09-05 に束ねた3本は、3本とも `technical` だった**（低ボラ＋モメンタム＋
短期リバーサル）。合成 t −0.14、最良の単独 +1.69 で、**符号が逆になった。**
`fundamental` が1本も入っていない束である。

その結末は動かさない（`docs/HYPOTHESES.md`「因子探索は 2026-09-05 に閉じた」）。
ここで測り直すのは r ではなく、**複合型それ自体**である。`composite-gain` の
閾値には「曖昧域で財務系の再測定はしない」と書いてあり、**それには触らない。**

## 出典

**「低ボラ × バリュー」という組み合わせそのものの出典は持っていない。**
構成要素それぞれが俗説として語られているのを組んだもので、**この組を誰かが
主張しているのを見たわけではない。**

**あとから論文を探して埋めない**（`docs/PURPOSE.md`）。空欄のほうが正直である。

## §0. 検出可能性ゲート（**最初に埋める。ここで落ちたら封印しない**）

### 封印しない線 — **測る前に置く**

> **IS で推定した合成の α が、実測した往復費用の 3 倍を下回ったら封印しない。**

**数字ではなく規則で置く。** 費用は入れ替わり率で決まり、入れ替わり率は測る
まで分からない。**「年 X%」と決め打つと、その X がどこから来たかを書けない。**

**3倍にするのは #8 と同じ理由である。** 費用を超えるだけの下限を置くと、#7 が
入った帯にまっすぐ入る。帯に入った判定は「無い」と「あると言い切れない」を
分けられないまま、**判定を1回消費する。**

### IS で試す組み合わせは **1通りだけ**（測る前に決めた）

> **等加重の z スコア合算、1通り。重みは動かさない。**

**予算20本の補正は、IS の中で何通り試したかを知らない。** IS で何通りも回して
最も良いものを封印すれば、補正はその試行を覆わないまま `t ≥ 3.02` を当てる
ことになる。`composite.Design.tries_in_is` がこの数を持ち、`composite-gate` が
超過を弾く。

**重みを外して回したくなったら、それは2通り目である。** そのときは封印しない。

### 見込みをどこから取るか — **段2（自分の IS から推定する）**

**段1は使えない。** この組を報告した文献値を持っていない。

段2の条件3つ。

1. **上の「費用の3倍」を、測る前に書いてコミットした。** ✅
2. **IS と OOS は1日も重ねない。** §6 で日付を固定する ✅
3. **検出できる差は OOS の期数（104）で計算する。** 全期間ではない ✅

### 埋めるもの

**すべて `research\複合の関門.bat`（`composite-gate`）が出す。** IS だけを読む。

| 項目 | 値 | どこから取ったか |
|---|---|---|
| 1期あたりのSD（α） | **未測定** | IS の月次、費用引き後 |
| 重なりの膨張 | **未測定** | Newey-West と素の分散の比 |
| 判定に使える期数 | **104** | OOS の月数（2018-01〜2026-08） |
| 見込みの下限 | **未測定** | 段2。IS の推定の 95% の幅の下側 |
| 見込みの上限 | **未測定** | 段2。同上 |
| 1ヶ月あたりの銘柄 | **未測定** | **PBR を要求すると断面が痩せる** |

## §1. 仮説

**低ボラと低PBR を両方満たす銘柄群が、どちらか一方だけの銘柄群を上回る。**

### 合格には「最良の構成要素単独を上回る」ことが要る

`docs/PURPOSE.md` の複合型ルール4である。**合成の α が正で `t ≥ 3.02` でも、
低ボラ単独のほうが良ければ不合格。** 束ねた意味が無いからである。

**最良は後から選ぶ。** そのぶん分母が大きくなり、判定は厳しく出る。
**その向きが安全な側である。**

### 脚には判定を出さない

`VALUE_JP`（#10）と `LOWVOL_JP`（#7）の数字は、**この判定の合格線として**
同じ盤面・同じ月で計算する。**それは脚の判定ではない。**

- #7 は 2026-09-05 に**別の期間**（2014-01〜2021-08）で判定済みである。ここで
  出る数字はその判定を上書きしない
- #10 は**まだ封印していない。** ここで出る数字を「#10 の判定」と読まない

**累計本数に数えるのは、この複合1本だけである。**

## §2. ユニバース

- 日本株。**上場廃止銘柄を含む**（生存バイアスを入れない）
- 流動性の下限は #7 と同じ
- **外国会社の株式は入らない**（2026-09-16）
- `pbr` が空・0 以下の銘柄月は外す。**0 で埋めない**

## §3. 並べ替えと分位

- 低ボラ … 日次リターンの標準偏差（250営業日）。**符号を反転**して「大きい
  ほど買う側」にそろえる
- バリュー … **−log(PBR)**。生の PBR は右に長い裾を持ち、そのまま z スコアに
  すると上位の数銘柄が重みを独占する
- **月ごとに各因子を標準化してから、等加重で足す**（`Panel.composite`）
- 昇順に5分位。**差 ＝ 分位1 − 分位5**（合成 signal の大きい側 − 小さい側）

## §4. 売買ルール

- 月末に組み替え、翌月末まで保有。**窓が重ならない**
- 費用は**実測した入れ替わり率 × 往復 0.40%**

## §5. 評価指標

- **主要指標は α**（合成スプレッド − β×指数）。β は **IS で固定**して OOS に
  当てる。判定期間から推定すると、判定期間の情報でその期間を調整することになる
- 生の差も毎回併記する
- 構成要素ごとの単独も、**同じ盤面から**同時に出す

## §6. 期間分割

| | 期間 | 月数 |
|---|---|---|
| IS（推定に使う） | 2009-01 〜 2017-12 | 108 |
| **OOS（判定。一度だけ）** | **2018-01 〜 2026-08** | **104** |

**1日も重ねない。** 保有が月をまたぐので、IS の最後の月の**退場日**まで見ても
2018-01 に届かないことを実装で確かめる。

**2009年より前は使わない。** `pbr` が 92% 以上埋まるのは 2009年からである。
