### 20% と 5営業日 は、下見で使った値である

**ここで選び直さない。** #10 は設計の選び方で IS の `t` が 2.8倍振れて封印
できなかった。

### 不連続を外す理由

**調整漏れの分割・併合は、まさに「5営業日で −20%」に見える。** 1:2 の分割は
−50% である。壁の下見の1回目で、これを外さずに **SD 273%／イベント日** を
出した（2026-09-19）。

### 権利落ちは外すが、**0 が想定である**

**20% の下げを配当で作ることはできない**（利回りがそれだけ必要になる）。
**それでも外す**——特別配当のような大きいものが在りうるし、あれば**機械的な
値下がりで戻らない**ので、この説の事象としては偽物である。

**外した件数が 0 なら、それは想定どおりである。** #15 とは逆で、**ここで 0 で
ないほうが驚き**になる。

### だから IS は 2013年からである

`ExDate` は **2012-12-26 から**しか無い（#15 で数えた）。**外せる期間と外せ
ない期間を混ぜない**ので、#15 と同じ区切りにする。

## §7. 生存バイアス

**入りうる。そして、この説では向きが分かっている。**

急落した銘柄は上場廃止になりやすい。窓の途中で消えると「足の終わりを越えた」
として落ちるので、**落ちるのは最も悪く終わった側**である。

**ショートの取り高を測っているので、それは取り高を小さく見せる側**——つまり
**格言に不利な向き**である。`EventSample` が件数を別に数え、落ちた側の大きさ
（`truncated`）も出す。
