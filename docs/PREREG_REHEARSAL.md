# 事前登録 — `REHEARSAL`「乱数の signal」（陰性対照）

**状態：説ではない。予算に数えない。**（2026-09-17）

**これは世界について何も主張していない。** だから「当たりを引こうとした回数」に
入らない——多重検定の補正が数えたいのはそれである。

## なぜ作ったか

**このプロジェクトには対照が1本も無い。** §0 の関門も、判定の当てはめも、
**本物のデータの上でしか試していない。**

問いは1つ。**何も無いときに、この仕組みは合格を出すか。**

出したら、**仕組みが壊れている。** そこに合格が出ないことは、これまでの4本の
「封印せず」より強い保証になる——**あちらは関門で止まっており、判定そのものを
通していない。**

## 何を乱数にするか

> **signal だけ。** 月も universe もリターンも本物のまま。

**全部を乱数にしない。** 重なりも自己相関も消えてしまい、**いちばん確かめたい
部分が消える。** 20営業日の窓が重なることや、月次の系列が相関することを、
Newey-West がちゃんと拾えているか——それが見たい。

**種を固定する**（`SEED = 20260917`）。変えれば違う答えが出るので、記録に
残せなければ意味が無い。

**種を分けたら OOS が +1.29 から +0.77 に動いた。** 共有が効いていた形だが、
**どちらも1回ずつの引きなので、これも断定できない。** 1回の引きから言えるのは
「合格は出なかった」だけである。

**IS と OOS で同じ種を使わない**（OOS は `SEED + 1,000,000`）。乱数の流れが
共有されると、**2つが独立な引きにならない。** 最初はそうしていて、
IS +1.24・OOS +1.29 が揃って見えた——**偶然か共有のせいかを区別できなかった**
（2026-09-17）。

`spawn` ではなく定数のずらしにしたのは、**種を記録すれば手で再現できる**ように
するためである。

## §0 を通さない

**§0 は「一度きりの判定を、弱い設計に使わない」ための関門である。**

**判定を消費しないものには、守るものが無い。** だから通さない。**この理由を
書いておかないと、次に読む人が「対照は §0 を免れた」と読む。** 免れたのでは
なく、**当たる先が無い。**

## 判定

**合格は `t ≥ 3.02`**（予算20本）。本物とまったく同じ線である。

**期待は不合格。** 乱数に合格が出る確率は、片側で **0.125%** である。

## 1回では校正できない

400回回しても、`t ≥ 3.02` の期待値は **0.5回**である。**出る／出ないだけでは
何も分からない。**

**代わりに `t` の分布そのものを見る。**

| 項目 | 帰無なら |
|---|---|
| `t` の SD | **1.00** |
| `t` の平均 | 0.00 |
| `\|t\| ≥ 1.96` | 5.0%（**400回で測れる**） |
| `\|t\| ≥ 3.02` | 0.25%（400回では測れない） |

**SD が 1.15 なら、補正は足りていない。** `t ≥ 3.02` の実際の意味が、設計した
0.25% ではなく 0.6% 前後になる。**それは判定の線がすべて甘いということである。**

### 測った（2026-09-17、400回）

| 項目 | 実測 | 帰無なら |
|---|---|---|
| `t` の SD | **1.12** | 1.00 |
| `t` の平均 | +0.01 | 0.00 |
| `\|t\| ≥ 1.96` | **8.5%** | 5.0% |
| `\|t\| ≥ 3.02` | 0.75%（**3件。読めない**） | 0.25% |
| いちばん大きい `t` | +4.25 | — |

**`t ≥ 3.02` は 0.25% のつもりで、実際は 0.71% だった。** 判定の線を
**3.02 → 3.39** に上げた（`docs/HYPOTHESES.md`）。

**`|t| ≥ 3.02` の行は読まない。** 400回中3件では幅が広すぎる。**固いのは SD の
行**で、400回なら誤差は ±0.04 程度である。

**`いちばん大きい t +4.25` も驚くほどではない。** SD 1.12 で400回引けば、最大値
の期待値は 3.2 前後である。

**`CALIBRATION_LIMIT = 1.10` に根拠は無い。** 「1割ずれたら見過ごさない」という
目安であって、測って出した値ではない。**そう書いておく。**

## 主張できないこと

- **相場について何も言わない。** 乱数である
- **「この仕組みは正しい」とも言わない。** 言えるのは「**この帰無の下では、
  設計どおりの頻度でしか合格が出なかった**」だけである
- 別の帰無（例えば裾の重い分布）については何も言わない
