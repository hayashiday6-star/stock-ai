# 事前登録のひな形

新しい説を検証するときは、これを写して埋める。**§0 を埋める前に、それ以外を
書き始めない。**

`docs/HYPOTHESES.md` に行を足すのも忘れない（片方だけ直すと、どちらが本当か
分からなくなる）。

---

## §0. 検出可能性ゲート（**最初に埋める。ここで落ちたら封印しない**）

> **なぜ最初なのか。** #2 と #3 は封印した後で検出力不足が分かった。#7 は
> 封印前に気付いて「五分五分」と文書に書き、**そのうえで回して、負けた側に
> 落ちた。** 気付くだけでは足りなかった。止める場所が無かったからである。

### 埋めるもの

| 項目 | 値 | どこから取ったか |
|---|---|---|
| 1期あたりのSD | % | **判定に使わない期間**から。平均は見ない |
| 重なりの膨張 | x | 実測。月次で重ならないなら 1.0 前後 |
| 判定に使える期数 | | |
| 見込みの下限 | 年 % | **下の3段階のどれかで埋める。結果を見る前に置く** |
| 見込みの上限 | 年 % | |

### 見込みをどこから取るか — 3段階（2026-09-05 に追加）

**「文献から引く」しか手順が無いと、§0 は「日本で既に証明済みのものしか検証
できない関門」になる。** 未検証の説を検証することが原理的にできなくなり、
関門の目的と逆になる。段階を分ける。

| 段 | 条件 | 見込みの下限をどこから取るか |
|---|---|---|
| **1** | **同じ設計**で報告された文献値がある | それを引き写す |
| **2** | 無い | **自分の IS から推定する。** 下の3条件つき |
| **3** | IS でも推定できない | **封印しない** |

**「同じ設計」を緩めない。** 断面を近接度でソートして6〜12ヶ月保有する文献の
値を、イベント日から20営業日保有する設計の下限に使うことはできない。母集団の
作り方も窓も違う。**転記すれば「出典のある数字」の見た目をした別物が §0 に
入る。出典の無い数字より質が悪い**——検証できないものを、検証したように
見せることになる。

#### 段2 の条件（3つとも満たすこと）

1. **推定する前に「この値を下回ったら封印しない」と書き、コミットする。**
   数字を入れて書く。「見てから決める」は段2ではない
2. **IS と OOS は完全に排他。** 1日も重ねない
3. **§0 の「検出できる差」は、判定に使う期数——すなわち OOS の期数——で
   計算する。** 全期間の期数で計算してはいけない

3 は段1には無い制約である。**段1では全期間が判定に使えるが、段2では半分を
選別に使うので、判定に残る期数が減り、検出できる差が上がる。** ここを全期間の
まま計算すると、**IS で推定した効果を、全期間で計算した検出力と比べる**ことに
なる——尺度の違う2つを組み合わせる、このプロジェクトが繰り返し踏んできた形
そのものである。例外は出ない。

**段2 は「出典の無い数字」ではない。** 出典は自分の IS 期間で、再現可能で、
どのコミットのどの実行かまで書ける。禁じているのは会話に1度出ただけの追跡
できない数字であって、文書化された自分の測定値ではない。

#### 段2 で通したものは、段1 で通したものと同じ主張ではない

**記録に、どちらで通したかを必ず書く。**

| | §0 が答えているもの | 合格したときに言えること |
|---|---|---|
| 段1 | **検出力**（そもそも検出できるのか） | 事前に予測し、確認した |
| 段2 | **選別＋検出力**（IS で見込みがあり、OOS で検出できるか） | IS の選別を生き延び、OOS でも出た |

**段2 の合格は、段1 の合格より弱い主張である。** 段2 では「IS で良く見えた
から選んだ」が入っているので、同じ IS で多くの候補を見た場合、選んだ1本が
選別の産物である可能性が残る。**OOS が汚れているわけではない**（排他なので
検定統計量は汚れない）が、**言えることが違う。** 一覧にそう書く。

### 判定

```
uv run stock-ai power-gate --sd <SD> --periods <期数> --low <下限> --high <上限> --inflation <膨張>
```

**合格線は1つだけ。見込みの下限が、検出できる差を上回ること。**

中央値ではない。**中央値で通すと、「アノマリーが文献どおりに実在していても
五分五分」という検定を封印できてしまう。** #7 がそれだった。

| 結果 | 意味 | 次の一手 |
|---|---|---|
| 通す | 下限が検出できる差を上回る | 封印してよい |
| 通さない（またぐ） | 通るかどうかが運になる | 期数を増やすか、分散を下げる設計に変える |
| 通さない（届かない） | 上限すら届かない | 回しても不合格にしかならない。設計を変えるか閉じる |

### 通らなかったときに書くこと

**「検出力不足」で終わらせない。** 何期あれば足りるかを書く。

コマンドが出す表を写す。年数にすれば、手元の年数と引き算ができる。

### なぜ下限で見るのか — 偽陰性と偽陽性は等価ではない

通らない検定を回して不合格を得ると、**「効果が無い」と「小さすぎて見えない」の
区別が付かないまま説を1本失う。** 回さなければ、設計を直してから出直せる。

**判定は一度きりの資源である。** 通る見込みの薄い設計に使わない。

## §1. 仮説

何が、何に対して、どういう向きに効くと言っているのか。**機構**（なぜ残るのか）
も書く。「誰も見ていない」型か「知られているが制約があるので残る」型かで、
期待値の置き方が変わる。

## §2. ユニバース

市場・流動性の下限・ベンチマーク・最低銘柄数。**価格系列の不連続の扱いも
ここで決める**（1営業日 ±50% を超える動きは分割・併合の跡である）。

件数センサス（**リターンを計算しない**）の実測をここに書く。

## §3. 並べ替えと分位

何で並べ、いくつに割り、どれを買うのか。**測定窓を選んだ理由を、リターンを
見ずに決めた根拠とともに書く。**

## §4. 売買ルール

組み替え日・エントリー・エグジット・建玉・費用。**費用は仮定しない。**
センサスで測った入れ替え率から出す。

## §5. 評価指標

主要指標を1つに決める。**仮説が言っていることと、測る対象を合わせる。**
リスク調整後の話をしているなら、生の差ではなく α を測る。

副次指標は毎回併記するが、**判定には使わない。**

## §6. 期間分割

| | 期間 | 用途 |
|---|---|---|
| 推定 | | 分散とβのみ。**平均は見ない** |
| 判定 | | 合否判定。**一度だけ** |

`end` は「この日より後のデータを1つも使わない」という意味で実装する。
**組み替え日だけで切ると、保有期間が越えて伸びる。**

## §7. 生存バイアス

日付ごとの名簿があるか。無い期間はどこか。**直せないなら、その大きさの
見当を書く。** 実測は判定の後に行い、判定の入力には使わない。

**判定と診断で同じ universe を使う。** #7 は判定を db universe（その日に価格が
ある銘柄）で回し、診断を名簿ありと生存者のみで回した。診断の差（+0.059%／月、
t +3.96）は測れたが、**判定がその2つのどちらにどれだけ近いかは測れない。**
知るには判定を回し直すしかなく、それは2回目の判定になる。

バイアスの実測には**標準誤差と t も出す。** 平均だけ出すと、0 と区別が付くのか
分からないまま「バイアスは +0.059% だった」と次の登録に引用されていく。

## §8. 先読みバイアスのチェックリスト

- β や係数を判定期間から推定していないか
- 選抜窓と推定窓が分かれているか
- 名簿は「その日以前で最も新しいもの」を使っているか（全期間の和集合は
  **まだ上場していない銘柄を過去に置く**）

## §9. 主張できないこと

この検証で言えないことを、先に書く。

## §10. 中止条件

判定を回さずに閉じる条件。

## §11. 合格基準と読み方の表（**結果を見る前に確定させる**）

| 主要指標 | t | 読み方 |
|---|---|---|
| ≤ 0% | — | 効果なし。閉じる |
| 0% 〜 費用 | — | 費用を賄えない。閉じる |
| 費用 〜 検出できる差 | t < 2.0 | **構造的な帯。** 不合格だが「効果が無い」ではない |
| 費用 〜 検出できる差 | t ≥ 2.0 | 合格 |
| ≥ 検出できる差 | t < 2.0 | 点推定は十分だが有意でない |
| ≥ 検出できる差 | t ≥ 2.0 | **合格** |

**この表は人が読んで当てはめるのではなく、コードが当てはめる。**
判定が出てから基準が動きかけた前例がある。

## §12. 合格したときに何をするか（**封印前に決める**）

持ち方・比率・レバレッジの可否。**判定基準に含めない記録項目**（最大下落など）
があるなら、含めないと明記する。**含めれば2つ目の基準になり、多重検定になる。**

## §13. 判定（回した後に書く）

数字は出力から**引き写す**。文書の中で計算し直さない（二重管理になる）。

**言えることと言えないことを分ける。** 有意でない副次指標から読める話は、
有意性を付けない観察として記録する。
