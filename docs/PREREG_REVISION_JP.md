## §1. 仮説

**会社が業績予想を上方修正した後、株価は上がり続ける。**

### 逆の符号が出ても「発見」にしない

**差が有意に負（＝上方修正の後に下がる）だったとき、それはこの説の不合格で

## §2. ユニバース

| | 決めたこと | 理由 |
|---|---|---|
| 市場 | 東証（TOKYO PRO Market を除く） | 買えない銘柄を入れない |
| **決算と同じ日の修正** | **外す** | **#2・#3 と同じ日付集合を使わない。再開の前提そのもの** |
| 流動性の下限 | 売買代金 1億円／日（`pead.MIN_TURNOVER`） | 既存の登録と揃える |
| 貸借区分 | **問わない** | ロングのみなので空売りが要らない（#8 はここで 70% 落ちた） |
| 外国会社の株式 | **入らない** | 2026-09-16 に universe から外した |
| 価格系列の不連続 | 1営業日 ±50% を超える動きは除く | 既存と同じ |
| 上場廃止銘柄 | **含む** | 生存バイアスを入れない |
| **連結／単体** | **連結のみ**（`FNP`） | **混ぜない。** 下の追記 |

### 連結だけを見る（**2026-09-16 に明文化。抜けていた**）

§3 は「見る科目は `net_income`」としか書いていなかった。**連結か単体かを
書き分けていなかった。**

原本では連結が `FNP`、単体が `FNCNP` である。**`FNP` が空の行の 38% に
`FNCNP` が入っている**（実測。単体でしか予想を開示していない会社）。

**混ぜない。** 「連結と単体を取り違える」は `CLAUDE.md` が名指しで戒めている
形で、`FNCNP` を `FNP` の代わりに読むのはまさにそれである。**例外は出ず、
もっともらしい数字が出るだけである。**

**この説は「連結で通期予想を開示している会社」についてのものになる**（§9）。
流動性の下限が既に 70% を落としており、単体開示の会社は小型に寄るので、
**実際の損失は小さい見込みである。ただし数えていない。**

## §3. イベントの定義

> **`DocType == EarnForecastRevision` の開示のうち、会社予想が前回比
> **+5% 以上**に変わったもの。**

- 比べるのは**同じ会計年度の**通期予想。年度をまたいだ比較は「修正」ではない
- 見る科目は **連結の `net_income`**（`FNP`）。**単体（`FNCNP`）は使わない**（§2）
- +5% の出どころは `forecast_revision.DEFAULT_MIN_CHANGE`。**この登録のために
  決めた数字ではなく、既にコードにある値を引く**

### 並べ替えない

**修正幅で分位に割らない。** 二値の出来事として等加重で持つ。

**修正幅で並べるなら、それは別の1本である。** 割り方が1つの自由度になり、
**#3（SUE）はまさにその形で落ちている。**

## §4. 売買ルール

| | 決めたこと |
|---|---|
| イベント日 D | **開示日**（`disclosed_on`） |
| エントリー | **D+1 営業日の始値** |
| エグジット | **D+20 営業日の終値** |
| 建玉 | 1イベント1単位、等加重。**ロングのみ** |
| 費用 | 往復 0.4%（`reversal.COST_ROUND_TRIP`） |

### D の終値では入らない

**開示時刻に賭けない。** 予想修正は引け後に出ることが多いが、**多いことと
全部であることは別である。** D+1 の寄付きなら、いつ出ていても取れる。

### 窓を 20営業日にする理由

**#3・#6 と揃える。** リターンを見て決めていない。

**#8 のように機構から窓が出る説ではない**ので、既存と揃えるのが**いちばん
自由度の少ない決め方**である。

## §5. 評価指標

**主要指標：上方修正イベントの、市場対比の平均リターン（D+1 始値 → D+20 終値、
費用差引後）。符号は正を期待する。**

**主要指標は1つだけである。**

### 副次指標（**判定には使わない**）

| | 何が分かるか |
|---|---|
| 下方修正の同じ測り方 | 逆向きに出るか。**出なくても上方側の判定は変わらない** |
| D−5 〜 D の値動き | **開示より前に動いているか** |
| 決算と同じ日の修正の同じ測り方 | 外した集合が違う振る舞いをするか |
| 修正幅で分けた内訳 | **並べ替えの設計に使わない。** 見るだけ |

**副次を判定に使わない。** 使えば基準が2つ以上になり、多重検定になる。

## §6. 期間分割
