**甘いほうを採った。** 実装をまだ選んでいないので、**選んでいない実装のせいで

## §1. 仮説

**月末から月初にかけての数日は、それ以外の日より上がる。**

日本株について、**月の最終営業日から翌月3営業日目まで**の日次リターンの合計が、
**同じ月のそれ以外の日の平均**を、日数を揃えたうえで上回る。

### 出典

**格言そのものに数字は無い。** 2026-09-19 の会話でユーザーが検証候補の2位に
挙げた（`docs/CANDIDATES.md`）。挙げた根拠は「月末・月初という客観的な日付で
定義でき、給与、積立、年金、機関投資家のリバランスなど需給面の説明が可能」。

**文献は読めていない。** 一次資料がこの環境から取得できない。**§0 の数字には
使っていない。**

### 期待する向き

**正。** 窓の中が窓の外を上回る。

**向きを後から反転させない。** #9・#12 は IS が逆向きに出て、そこで閉じた。

## §2. ユニバース

**銘柄を選ばない。** これは市場全体の暦の話で、銘柄間の断面ではない。

測る系列は2つ。

| | 何か | 役割 |
|---|---|---|
| **`1306`** | TOPIX 連動 ETF（時価総額加重） | **線を当てるのはこちら。** 格言は「相場」について言っている |
| 等加重の宇宙 | その日に足のある JP 銘柄の等加重平均 | **併記する。** 効果が小型に偏っていないかを見る |

**加重の違いは、ここでは偏りを作らない。** #5・#8 では**等加重のバスケットから
時価総額加重の指数を引いて**いたので、加重差がそのまま下駄になった。**ここは
同じ系列の中で日どうしを比べる**ので、加重は効果の大きさを変えるだけで、
**無いものを在るように見せることはできない。**

**生存バイアスも同じ理由で入らない。** 上場廃止銘柄の扱いは窓の内外で同じである。

## §3. 窓の定義（**固定する。何通りも試さない**）

| 項目 | 値 |
|---|---|
| 窓の始まり | **月の最終営業日**（−1） |
| 窓の終わり | **翌月3営業日目**（+3） |
| 窓の長さ | **4営業日** |
| 暦 | **`1306` の営業日**。銘柄ごとの暦を使わない |

**この表から外れたことは一切しない。**

**窓を何通りも試すと、偶然に良い期間を見つけるだけになる**（ユーザーが候補の
時点でそう書いている）。#10 は設計の選び方で IS の `t` が 2.8倍振れて封印できな
かった。**−1〜+3 は文献でよく使われる形で、こちらが選んだものではない。**

**「祝日で4日に満たない月がある」と最初に書いたが、間違いだった**（2026-09-19
に実装して気付いた）。窓は**営業日で数えている**ので、祝日は暦の幅を伸ばすだけ
で、営業日の数は減らない。**欠けるのは系列の終わりだけ**である。

**それでも窓の日数は毎回数えて出す。** 書いた前提は、成り立つことを確かめる
（`CLAUDE.md`）。**4日でない月替わりがあれば警告が鳴る。**

## §4. 売買ルール

**売買しない。** 測るのは「窓の中の日の合計」と「窓の外の日の平均」の差だけで
ある。

```
1観測 = （その月の窓の中の日次リターンの合計）
      − （窓の中の日数 × その月の窓の外の平均日次リターン）
```

**費用は引かない。** 売買していないので引くものが無い。**その代わり §0 の線を、
将来売買するときの費用から置いた。**

**これは「儲かる戦略が在る」という主張ではない。** 言えるのは「その差が在る」
までである（§9）。
